## 1. GPU 딥러닝 개발 환경 구축

### 설치 순서 (반드시 이 순서대로 진행)
1. **엔비디아 드라이버** 설치
2. **CUDA** 설치
3. **cuDNN** 설치

> ⚠️ 최신 버전 GPU는 Windows에서 TensorFlow/PyTorch GPU를 공식 지원하지 않음 → 실무에서는 **WSL(Windows Subsystem for Linux)** 사용이 일반적. 이번 수업은 먼저 Windows에서 설치 후, 추후 WSL로 전환 예정.

### 엔비디아 드라이버
- 설치 확인 명령어: `nvidia-smi`
  - GPU 드라이버 버전, CUDA 버전(상한선) 확인 가능
  - 실무에서 매우 자주 사용하는 명령어
- 드라이버 다운로드 시 **사용자 정의(커스텀) 설치** 선택
  - ❌ 체크 해제 권장 항목: **Visual Studio Integration**(에러 빈발), 샘플(Samples), 문서(Documentation), Other Components(PhysX 등 불필요 항목)
  - 디스플레이 드라이버는 신버전 유지

### CUDA 설치
- 버전은 프로젝트/회사 환경에 맞춰 선택 (예: v11.2)
- CUDA 설치 시 드라이버가 롤백될 수 있으므로 해당 옵션은 체크 해제
- 설치 확인: `nvcc -V` (대문자 V) → CUDA 컴파일러 버전 확인
- 설치 경로 예시: `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.2`

### cuDNN 설치
- 회원가입 후 압축파일로 다운로드
- 압축 해제 후 `bin`, `include`, `lib(library)` 3개 폴더 + 파일들을 CUDA 설치 경로에 **덮어쓰기(관리자 권한)**
- CUDA 버전과 반드시 매칭되는 cuDNN 버전 설치 필요 (예: cuDNN 8.1.1 ↔ CUDA 11.2)

### 가상환경 생성 및 TensorFlow 설치
```bash
# 가상환경 생성 (예: TF29X-GPU)
conda create -n TF29X-GPU python=3.10

# 가상환경 활성화 후 TensorFlow 설치
pip install tensorflow==2.9.3
```
- 특정 버전을 모를 때는 `pip install tensorflow==` 처럼 등호만 입력하면 설치 가능한 버전 목록이 출력됨 (일명 "야매 스킬")
- 과거엔 `tensorflow`(CPU)와 `tensorflow-gpu`가 분리되어 있었으나, 현재는 하나로 통합됨

### NumPy 버전 충돌 이슈 (자주 발생하는 에러)
- TensorFlow 설치 시 NumPy 1.x / 2.x 버전 충돌로 임포트 에러 발생 가능
- 해결 방법:
```bash
pip uninstall numpy
pip install numpy==1.26.4
```
- 팁: 특정 마이너 버전을 피하고 싶을 때는 "그 이전 버전의 마지막 버전"을 설치하는 것을 선호 (예: 1.18.x대 회피 시 1.18의 최종 버전 대신 1.16 계열 등)

### 설치 확인 코드
```python
import tensorflow as tf
print(tf.__version__)

print(tf.config.list_physical_devices('GPU'))
# 결과 예: [PhysicalDevice(name='/physical_device:GPU:0', device_type='GPU')]

if tf.config.list_physical_devices('GPU'):
    print('GPU 사용 가능')
else:
    print('CPU만 사용')
```
- 가상환경별로 CUDA/cuDNN/TensorFlow 버전이 맞지 않으면 GPU가 인식되지 않고 CPU로만 동작함 (예: 다른 가상환경에서 실행 시 "GPU 없음"으로 출력됨)

### 실무 팁
- 회사마다 TensorFlow 버전이 다름 (구버전 그대로 유지하는 회사도 많음, TensorFlow 1.x를 쓰는 곳도 존재)
- 버전 조합(드라이버/CUDA/cuDNN/TensorFlow/PyTorch)은 항상 **명세(기록)해둘 것**
- 설치 경험을 많이 쌓아야 하며, 실무에서는 새 GPU/버전이 나올 때마다 재테스트 필요
- AI로 대체하지 말아야 할 것: **직접 코드 작성**, **검색하라고 지시한 항목의 검색** — 이 두 가지는 AI에게 맡기지 말 것 (그 외에는 AI 활용 허용)

## 2. CNN(합성곱 신경망) 핵심 개념

### 이미지의 수치화
- 이미지는 픽셀 단위로 구성되며, 각 픽셀은 밝기값 **0~255** 를 가짐 (0=검정, 255=흰색, 반대로 정의하는 경우도 있음)
- 컬러 이미지는 R, G, B 3개 채널로 구성 → 모두 255면 흰색, 모두 0이면 검정색
- 흑백 이미지의 채널 수는 1, 컬러는 3
- 이미지 데이터를 넣으면 결국 CNN도 `Y = WX + B` 형태의 연산 구조

### 이미지 데이터의 shape (4차원)
- 형태: **(데이터 개수, 세로, 가로, 채널)**
- 예: 8x8 흑백 이미지 30장 → `(30, 8, 8, 1)`
- 예: 100x100 컬러(증명사진 크기) 이미지 30장 → `(30, 100, 100, 3)`
- 훈련 시 이미지의 가로/세로/채널은 반드시 동일해야 함 (크기가 다르면 전처리로 통일 필요)
- 데이터 개수(장수)는 훈련 가능 여부와 무관 (30장이든 6만장이든 shape만 맞으면 됨)

### 컨볼루션(Convolution) 연산
- 이미지를 **커널 사이즈(kernel size)** 단위로 조각조각 잘라서 필터와 곱하고 더하는 연산 (행렬 연산)
- 예: 10x10 이미지를 3x3 커널로, 스트라이드 1로 통과 → 결과 크기: `10 - 3 + 1 = 8` → `8x8`
- 일반 공식: `출력 크기 = 입력 크기 - 커널 사이즈 + 1`
- 이미지 처리는 주로 **Conv2D** 사용 (Conv1D, Conv3D도 존재)
- 컨볼루션 레이어는 보통 한 개만 쓰지 않고 최소 2~3개 이상 겹쳐 사용 (예: VGG16은 다수의 컨볼루션 레이어로 구성)

### Keras Conv2D 레이어 구성 예시
```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D

model = Sequential()
model.add(Conv2D(10, (2, 2), input_shape=(5, 5, 1)))  # 필터(출력노드) 10개, 커널사이즈 2x2
model.add(Conv2D(2, (3, 3)))  # 두 번째 컨볼루션 레이어

model.summary()  # 각 레이어 통과 후 shape 변화 확인
```
- `input_shape`은 전체 데이터 shape에서 **데이터 개수(행)를 뺀 나머지** (예: `(60000, 5, 5, 1)` → `input_shape=(5,5,1)`)
- `model.summary()`로 레이어 통과 시마다 크기가 줄어드는 것을 확인 가능

### 용어 정리
- **커널 사이즈(kernel size)** = 필터(filter)라고도 부름 → 혼동 방지를 위해 강의에서는 "커널 사이즈"로 통일
- CNN은 1970~80년대에 Yann LeCun 등이 고안한 개념 (당시 컴퓨팅 파워 한계로 실용화가 늦어짐)

## 3. 이미지 데이터 전처리(스케일링)

이미지는 픽셀 값 범위(0~255)를 이미 알고 있으므로 최소/최대값 기반 스케일링이 간단함.

### 방법 1: 0~1 범위로 스케일링 (Min-Max, 최소값=0 고정)
```python
X_train = X_train / 255
X_test = X_test / 255
```

### 방법 2: -1~1 범위로 스케일링 (이미지 처리에서 자주 사용)
```python
X_train = (X_train - 127.5) / 127.5
X_test = (X_test - 127.5) / 127.5
```
- 두 방법 중 어느 것을 쓸지는 하이퍼파라미터 튜닝(전처리 실험) 영역 — 결과가 더 좋은 쪽 선택
- **X만 스케일링**, Y(라벨)는 스케일링하지 않음
- Scaler는 `X_train`으로 `fit` 후 `X_test`에도 동일하게 적용해야 함 (이미지의 경우 최소/최대값이 고정(0~255)이라 간단히 나눗셈으로 처리 가능)

## 4. MNIST 데이터셋 실습

```python
from tensorflow.keras.datasets import mnist

(X_train, Y_train), (X_test, Y_test) = mnist.load_data()

print(X_train.shape)  # (60000, 28, 28) — 흑백이라 채널 차원 생략됨
print(X_test.shape)   # (10000, 28, 28)

print(X_train[0])     # 0~255 사이의 픽셀 값 행렬
print(X_train.max(), X_train.min())  # 최대/최소값 확인

import pandas as pd
print(pd.Series(Y_train).value_counts())  # 클래스별 데이터 개수 확인
print(pd.Series(Y_test).value_counts())
```

- 전체 7만 장 (훈련 6만 장 + 테스트 1만 장), 0~9 숫자 손글씨 이미지
- 각 클래스(0~9)당 대략 6,000장 내외로 고르게 분포 (클래스 불균형 없음)
- 흑백 데이터라 채널 차원이 생략되어 있음 → 실제로는 `(60000, 28, 28, 1)`로 reshape 필요
- 시각화: `matplotlib.pyplot.imshow()` 사용
