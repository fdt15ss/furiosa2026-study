# 딥러닝 22일차 정리 — 활성화 함수(Activation Function) 직접 구현

> 오늘 주제: 시그모이드·탄젠트·ReLU 이후, **ReLU 변형 계열 활성화 함수**를 numpy로 직접 구현하고 그래프로 비교
> 참고 코드: `keras78_01 ~ 08` (Keras activation 계열 실습)
> ※ 녹취 인식 오류(NELLO/LELO → ReLU, 실루 → SiLU, 미씨 → Mish, 엘로 → ELU, 셀루 → SELU 등)는 문맥에 맞게 바로잡아 정리함

## 1. 오늘의 흐름 한눈에 보기

| 순서 | 활성화 함수 | 핵심 수식 | 건드리는 영역 |
|---|---|---|---|
| 1 | **ReLU** | `max(0, x)` | 음수 → 0 |
| 2 | **SiLU (= Swish)** | `x * sigmoid(x)` | 음수 부분 보완 |
| 3 | **Mish** | `x * tanh(softplus(x))` | 음수 부분 보완 |
| 4 | **ELU** | `x (x>0)`, `α(eˣ-1) (x≤0)` | 음수 → -α로 수렴 |
| 5 | **SELU** | `λ · ELU(x, α)` | 양수·음수 모두 |
| 6 | **Leaky ReLU** | `x (x>0)`, `αx (x≤0)` | 음수 기울기 유지 |

- 공통점: 모두 **ReLU의 변형** → 대부분 **음수 쪽**을 건드리고, **양수 쪽은 선형(linear)** 이 좋다는 흐름
- 공통 실습 틀: 함수 정의 → `x = np.arange(-5, 5, 0.1)` → `y = f(x)` → `plt.plot(x, y)` → `plt.grid()` → `plt.show()`

## 2. ReLU를 `np.maximum`으로 구현

### 2-1. 아이디어
- 입력값 `x`와 `0`을 **비교해서 큰 값만 남긴다**
  - `300 vs 0` → 300 / `25 vs 0` → 25 / `-1 vs 0` → 0 / `-27,533,727 vs 0` → 0
- 즉 **0 이하는 0, 0 초과는 x 그대로**

### 2-2. 코드
```python
import numpy as np
import matplotlib.pyplot as plt

def relu(x):
    return np.maximum(0, x)   # 0과 x 중 큰 값
```

### 2-3. 람다(lambda)로 바꾸기
```python
relu = lambda x: np.maximum(0, x)
```
- 람다 문법 = **`lambda 매개변수: 리턴값`**
- 함수 정의(`def`)와 완전히 같은 동작 → 기존 `def` 함수는 지우거나 주석 처리 가능
- 오늘 실습에서는 만든 함수를 전부 람다로도 한 번씩 바꿔봄

## 3. SiLU (Swish)

### 3-1. 수식
```
SiLU(x) = x * sigmoid(x) = x * 1 / (1 + e^(-x))
```

### 3-2. 코드
```python
def silu(x):
    return x * (1 / (1 + np.exp(-x)))

silu = lambda x: x * (1 / (1 + np.exp(-x)))
```

### 3-3. 포인트
- **2017년 구글이 Swish로 발표** → 논문에서 `Swish`라고 나오면 **SiLU와 같은 것**
  - Keras의 `activation`에는 `swish`가 아니라 **`silu`** 로 이름이 올라가 있음
- 시그모이드와 헷갈리기 쉬움 → **"x에 시그모이드를 곱한 것"** 이라고 정확히 기억
- ReLU의 약점(음수 영역이 전부 0으로 죽음)을 **살짝 보완** → 성능이 **은근히** 좋아질 때가 있음 (항상은 아님!)
- 선생님 의견: "논문에는 좋은 말이 많지만, 그냥 곱해봤더니 결과가 좋았던 것 같다" → **결과를 보고 판단**하는 영역

## 4. Mish

### 4-1. 수식
```
Mish(x) = x * tanh(softplus(x)) = x * tanh(log(1 + e^x))
```

### 4-2. 코드
```python
def mish(x):
    return x * np.tanh(np.log(1 + np.exp(x)))

mish = lambda x: x * np.tanh(np.log(1 + np.exp(x)))
```

### 4-3. SiLU vs Mish
- 그래프를 겹쳐 그리면 **거의 비슷한 모양**
- 차이는 **연산량**
  - SiLU: `x * sigmoid(x)` → 단순
  - Mish: `tanh` + `log` + `exp`가 중첩 → **연산량이 더 많음**
- 수만~수십만 건 정도의 데이터에서는 큰 차이 없음
- 결론: **둘 다 써보고 좋은 쪽 선택**, 연산량을 조금이라도 줄이고 싶으면 **SiLU**

---

## 5. ELU

### 5-1. 수식
```
ELU(x) = x                      (x > 0)
       = α * (e^x - 1)          (x ≤ 0)
```

### 5-2. 코드 (조건식을 불리언 곱셈으로 표현)
```python
def elu(x, alpha=1):
    return (x > 0) * x + (x <= 0) * (alpha * (np.exp(x) - 1))
```
- Python에서 `x > 0`은 **True(1) / False(0)** → 불리언을 곱해서 **조건에 맞는 항만 살리고 나머지는 소멸**
  - `x`가 양수 → 앞 항만 살아남아 ReLU처럼 `x` 그대로
  - `x`가 음수 → 뒤 항만 살아남아 `α(eˣ - 1)`
- `alpha`는 **인자로 받도록** 함수를 수정해야 함 (함수 안에서 정의되지 않으면 `NameError`)

### 5-3. α의 의미
- **음수 쪽 최종 종착지(수렴값)** 를 조절하는 하이퍼파라미터
  - `α=1` → -1로 수렴 (기본값)
  - `α=2` → -2로 수렴
  - `α=1,203,700` → -1,203,700으로 수렴
- ReLU와 달리 **음수 성분이 살아남고**, 값이 **아래로 내려갔다가 다시 올라오는** 모양이 아니라 **α에 수렴**

### 5-4. 미분 관련 메모
- `α ≠ 1`이면 **0에서 좌/우 기울기가 달라져** 미분 불가능한 지점이 생김
- ReLU도 0에서 미분이 안 되지만 실제로는 잘 학습됨 → **활성화 함수는 미분 가능하게 취급해서 사용**
- 미분 직접 계산은 **나중에 손으로 해보는 시간**이 있을 예정 (오늘은 생략)

## 6. SELU

### 6-1. 수식
```
SELU(x) = λ * x                    (x > 0)
        = λ * α * (e^x - 1)        (x ≤ 0)
```
- ELU에 **스케일 상수 λ를 곱한 형태** → **양수 쪽도, 음수 쪽도 둘 다** 건드림

### 6-2. 고정 상수 (논문 기본값)
```
α ≈ 1.6732632423543772
λ ≈ 1.0507009873554805
```
- 선생님: "이게 가장 좋은 값이라는 게 아니라, **기본값으로 괜찮다**는 의미"
- 정확한 값이 기억나지 않으면 **인터넷에서 SELU 고정 상수 검색**해서 쓰면 됨 (적당히 써도 무방)

### 6-3. ⚠ 파이썬에서 `lambda`를 변수명으로 못 쓰는 이유
- 논문에서는 `λ(lambda)`지만, **`lambda`는 파이썬 예약어(람다 함수 키워드)** 라서 변수명으로 사용 불가
- 그래서 코드에서는 **`gamma`** 등 다른 이름으로 대체 (블로그/자료마다 `gamma`, `scale` 등으로 표기)

### 6-4. 코드
```python
def selu(x, alpha=1.6732632423543772, gamma=1.0507009873554805):
    return gamma * ((x > 0) * x + (x <= 0) * (alpha * (np.exp(x) - 1)))

selu = lambda x, alpha=1.6732632423543772, gamma=1.0507009873554805: \
    gamma * ((x > 0) * x + (x <= 0) * (alpha * (np.exp(x) - 1)))
```

### 6-5. 해석
- `x > 0` → 기울기가 **약 1.05배** 커져서 양수 영역이 살짝 더 가팔라짐
- `x ≤ 0` → ELU처럼 특정 값에 수렴 (λ가 곱해진 만큼 이동)
- **정리**: "ELU를 이겨보자"는 목적으로 **ReLU 모양은 유지하면서 특정 부위만 변형**한 활성화 함수

## 7. Leaky ReLU

### 7-1. 수식
```
LeakyReLU(x) = x          (x > 0)
             = α * x      (x ≤ 0)      # α = 0.01 (기본)
```

### 7-2. 코드 (두 가지 방식)
```python
# ① 불리언 곱셈 방식
def leaky_relu(x, alpha=0.01):
    return (x > 0) * x + (x <= 0) * (alpha * x)

# ② np.where 방식 (조건 ? 참 : 거짓)
def leaky_relu2(x, alpha=0.01):
    return np.where(x > 0, x, alpha * x)

leaky_relu = lambda x, alpha=0.01: np.where(x > 0, x, alpha * x)
```
- 두 방식은 **같은 수식**, 결과 그래프도 동일
- 음수 영역이 **0으로 죽지 않고 기울기 0.01만큼 살아남음** → 이 역시 **ReLU의 변형형**

### 7-3. 나만의 활성화 함수 만들기 (농담 섞인 예시)
- 예: `relu(x) * 2` → "0 이하는 0, 0 초과는 기울기 2" → 이것도 하나의 활성화 함수
- 이런 식으로 만들고 **성능 좋은 것만 골라 논문 쓰면 된다** (선생님 농담, 핵심은 *변형은 어렵지 않다*)

## 8. 오늘의 핵심 정리 (시험 대비)

1. **ReLU = `np.maximum(0, x)`** — 0과 x 중 큰 값
2. **SiLU = Swish = `x * sigmoid(x)`** — 구글 2017 Swish 논문, Keras에서는 `silu`
3. **Mish**는 SiLU와 비슷하지만 **연산량이 더 많음**
4. **ELU의 α** = 음수 쪽 최종 수렴값 (기본 1)
5. **SELU** = ELU × λ, α·λ는 **고정 상수**(1.6733 / 1.0507), 코드에서 `lambda` 대신 `gamma` 사용
6. **Leaky ReLU의 α** = 음수 구간 기울기 (기본 0.01)
7. 불리언 곱셈 / `np.where` 으로 **조건식을 벡터 연산**으로 처리
8. 어떤 활성화 함수가 항상 좋다는 건 **없음** → **하이퍼파라미터 선택지 중 하나**
   - 좋으면 쓰고, 안 좋으면 다른 걸 쓰면 됨
   - α, λ까지 튜닝하려면 **그리드 서치**를 쓸 수도 있으나 비용이 큼 → 활성화 함수 자체를 바꿔 보는 편이 나을 수도 있음
   - 명확히 "이게 최고"인 게 있다면 이미 **고정값**이 되어 있었을 것

## 9. 파이썬 / 개발환경 팁

- **람다 함수**: `lambda 매개변수: 리턴값` — 간단한 함수는 `def` 대신 한 줄로
- **기본값 인자**: `def f(x, alpha=1)` — 호출 시 생략 가능, 필요하면 바꿔서 전달
- **예약어 주의**: `lambda`, `def`, `class` 등은 변수명 사용 불가
- **파일명 규칙**: 오늘 실습 파일명(`keras78_...`)처럼 **원래 이름 그대로 복사**해서 쓰는 게 편함 (대소문자 구분은 크게 신경 쓰지 말 것)
