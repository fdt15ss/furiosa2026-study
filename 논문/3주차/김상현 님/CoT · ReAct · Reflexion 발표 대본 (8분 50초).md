## 1. 표지 (0:28)

안녕하세요. 오늘은 언어 모델이 생각하고, 행동하고, 반성하는 방법을 다룬 세 논문을 소개합니다. CoT, ReAct, Reflexion입니다. 앞에서 세 논문을 짧게 정리하고, 뒤에서는 제가 이 방법들을 8B 모델로 직접 돌려 본 결과를 보여 드리겠습니다. 세 논문은 모두 모델을 다시 학습시키지 않고, 프롬프트와 실행 방식만 바꿔서 성능을 올렸다는 공통점이 있습니다.

## 2. 세 논문의 관계 (0:31)

세 논문은 시간순으로 이어진 진화 계보가 아닙니다. 서로를 감싸는 세 겹으로 보는 편이 맞습니다. 가장 안쪽의 CoT는 한 번의 생각입니다. ReAct는 그 생각 사이에 행동과 관찰을 넣어 한 번의 시도를 꾸리고, Reflexion은 시도가 끝나면 성공과 실패를 판정해서, 실패했으면 이유를 글로 써 다음 시도에 넘깁니다. 바깥 겹일수록 더 긴 시간의 피드백을 다룹니다. 세 논문 모두 모델의 가중치는 건드리지 않습니다.

## 3. CoT (0:43)

먼저 CoT입니다. 표준 프롬프팅은 질문을 주면 곧바로 답을 냅니다. CoT는 풀이가 담긴 예시 8개를 프롬프트에 넣어서, 모델이 답 앞에 풀이를 단계별로 쓰게 합니다. 예를 들어 테니스공 5개에 3개들이 2통을 더 샀다면, 5 더하기 6으로 11이라고 풀이를 적게 합니다. 논문의 발견은 세 가지입니다. 약 1000억 파라미터 이상의 큰 모델에서 효과가 나타나고, 수학 문제 GSM8K에서는 성능이 두 배 넘게 올랐습니다. 그리고 풀이가 반드시 답 앞에 있어야 합니다. 답을 먼저 쓰게 하면 효과가 없었습니다.

## 4. ReAct (0:38)

ReAct는 CoT의 생각에 행동을 더했습니다. 모델이 Thought, Action, Observation을 번갈아 씁니다. 행동은 위키백과의 검색, 조회, 종료 세 가지이고, 검색 결과가 다음 생각의 재료가 됩니다. 효과는 오류 분석에서 보입니다. HotpotQA에서 CoT는 실패의 56%가 환각이었는데, ReAct는 0%였습니다. 대신 같은 행동을 되풀이하는 추론 오류가 늘었습니다. 의사결정 과제 ALFWorld에서는 성공률 71%로, 행동만 하는 방식의 45%를 크게 넘었습니다.

## 5. Reflexion (0:40)

Reflexion은 시도와 시도 사이에서 배웁니다. Actor가 시도하면 Evaluator가 성공인지 실패인지 판정하고, 실패하면 자기 성찰 모델이 무엇이 왜 틀렸는지를 글로 써서 메모리에 쌓습니다. 이 메모가 다음 시도의 프롬프트에 들어가고, 가중치는 바뀌지 않습니다. 결과는 HumanEval 91%로, 당시 GPT-4의 80%를 넘었습니다. 하지만 오른쪽 숫자가 더 중요합니다. 코드 테스트 없이 반성만 하면 0.52로, 기준선 0.60보다 오히려 떨어집니다. 평가 신호가 부실하면 반성도 소용이 없습니다.

## 6. 같은 질문, 세 방식 (0:33)

같은 질문을 세 방식으로 풀어 보겠습니다. 두 작가의 공통 직업을 묻는 HotpotQA 질문입니다. CoT는 내부 지식만으로 답하다가 시나리오 작가까지 넣어서 틀립니다. 가운데 ReAct 열은 논문에 실린 예가 아니라, 설명하려고 제가 구성한 흐름입니다. 두 사람을 각각 검색해 비교하고 소설가로 답합니다. Reflexion은 첫 시도가 오답 판정을 받으면, 두 사람의 직업이 같다고 잘못 가정했다고 반성하고, 두 번째 시도에서 정답을 냅니다.

## 7. 세 방법 비교 (0:29)

세 방법을 나란히 놓으면, 한 겹을 더할 때마다 약점의 종류가 바뀝니다. CoT는 단순하고 싸지만 환각으로 실패합니다. ReAct는 환각을 없애는 대신 반복 루프와 검색 실패가 생깁니다. Reflexion은 재시도로 개선하지만, 평가가 약하면 틀린 교훈을 쌓습니다. 그래서 결합이 낫습니다. ReAct 논문에서도 ReAct가 막히면 CoT-SC로 넘기는 방식이 HotpotQA 최고 점수를 냈습니다.

## 8. 재현 실험 설계 (0:35)

여기부터는 제가 직접 돌린 재현 실험입니다. 논문과 공식 코드의 프롬프트, 예시, 루프, 평가 방식을 그대로 쓰고, 바꾼 것은 두 가지뿐입니다. 모델은 PaLM 540B 대신 로컬의 라마 3.1 8B를 썼고, 위키백과는 API로 접속했습니다. 통신 실패 같은 실행 오류는 막아서 기록했지만, 모델이 틀린 답을 내는 것은 고치지 않았습니다. 고치면 그 효과가 논문 방법 덕분인지 보정 덕분인지 알 수 없습니다. 규모는 수학 8문제, HotpotQA 5문제입니다.

## 9. 결과 ① 수학 CoT (0:39)

첫 결과는 CoT입니다. 같은 예시 8개에서 풀이를 넣느냐 빼느냐만 다르게 했습니다. 수학 8문제에서 Standard는 2문제, CoT는 6문제를 맞혔습니다. 논문의 PaLM 540B도 17.9에서 56.9로 올랐으니 방향은 같습니다. 다만 논문은 작은 모델에서는 효과가 없다고 했는데, 8B에서도 효과가 났습니다. 8문제라 우연일 수 있고, 요즘 모델은 풀이 데이터를 많이 학습했을 수도 있습니다. 이건 제 추측입니다. 그래서 이 결과는 방향이 같다는 정도로만 받아 주시면 됩니다.

## 10. 결과 ② HotpotQA 표 (0:36)

두 번째는 HotpotQA 5문제를 다섯 방법으로 푼 표입니다. 같은 5문제를 다섯 방법이 모두 풀었고, 정답 수는 Standard 2, CoT 3, Act 2, ReAct 2, Reflexion 2입니다. 논문 수치도 CoT가 ReAct보다 조금 높아서 순서는 비슷합니다. 하지만 한 문제가 20%포인트라서, 이 표는 순위가 아니라 사례로 봐야 합니다. 칸 아래 작은 글씨가 틀린 방식입니다. 통신 실패라고 적은 두 칸은 위키백과 접속이 일시적으로 끊긴 경우라 모델 탓만은 아닙니다.

## 11. 맞힌 답의 근거 (0:39)

정답률만 보면 CoT가 가장 좋아 보입니다. 그런데 CoT가 맞힌 3문제의 풀이를 열어 보면 셋 다 사실이 틀렸습니다. 협업한 제독을 Bobby Ray Inman이라고 썼는데 실제로는 William Crowe입니다. James Worthy는 2월 30일생이라고 했는데 그런 날짜는 없습니다. 정확 일치 채점은 답만 보니까 이것들이 모두 정답으로 세어집니다. 논문이 거짓 양성이라고 부른 경우입니다. 오른쪽 ReAct는 같은 질문에서 Crowe를 검색하고, Clinton 정부 때 대사였다는 문장을 읽고 답합니다. 근거가 남습니다.

## 12. ReAct가 틀린 방식 (0:36)

ReAct가 틀린 방식은 두 가지입니다. 왼쪽은 반복 루프입니다. 첫 검색에서 Irene Jacob의 출연작이 이미 나왔는데, 질문에 철자가 틀린 Stuart Bird가 있어서 없는 이름을 계속 검색하다 7스텝을 다 썼습니다. 논문에서도 ReAct 실패의 47%가 이런 추론 오류였습니다. 오른쪽은 표기 불일치입니다. 제작자 세 명을 다 적어서 사실로는 맞지만, 정답이 한 명이라 오답이 됩니다. 두 경우 모두 모델이 몰라서가 아니라, 검색 환경과 채점 규칙에서 생긴 실패입니다.

## 13. 결과 ③ Reflexion (0:36)

세 번째는 Reflexion입니다. 1차에서 맞힌 2문제는 그대로였고, 틀린 3문제는 세 번씩 시도했지만 끝내 못 맞혔습니다. 반성문은 프롬프트에 있는 예시 반성과 거의 같았고, 원인 진단도 빗나갔습니다. 제작자 문제는 답에 세 명을 다 적어서 틀렸는데, 모델은 검색 순서가 문제라고 했습니다. 이건 논문 부록과 같은 방향입니다. 약한 모델인 starchat-beta는 반성해도 0.26 그대로였고, 저자들은 자기 교정이 큰 모델에서 나타난다고 정리했습니다.

## 14. 재현 결과 정리와 한계 (0:36)

정리하면, CoT는 풀이가 정답률을 올린다는 점이 논문과 같았고, 8B에서도 효과가 났다는 점이 달랐습니다. ReAct는 정답 수가 CoT와 비슷했고 실패 유형도 논문과 같았습니다. Reflexion은 개선이 없었는데, 약한 모델에서는 효과가 없다는 논문 부록과 맞습니다. 한계도 분명합니다. 문제가 5개와 8개뿐이고, 온도를 0으로 해도 출력이 갈린 경우가 있었고, 통신 실패가 두 건 섞였습니다. 다음에는 30문제를 세 번씩 돌리고 더 큰 모델과 비교하겠습니다.
