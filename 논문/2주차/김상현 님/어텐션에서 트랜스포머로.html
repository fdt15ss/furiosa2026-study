01 · Background

출발점: 벡터 하나에 갇힌 문장

  • 긴 문장일수록 c 하나에 정보가 다 담기지 않음
  • RNN: hₜ가 hₜ₋₁에 의존 → 문장 안에서 병렬화 불가
  • CNN: 병렬화는 되지만 먼 두 위치를 잇는 연산 수가 거리에 따라 증가
어텐션 이전의 seq2seq는 문장을 고정 길이 벡터 하나로 요약해 긴 문장에서 정보가 손실됐습니다. 논문은 여기에 더해 RNN의 순차성과 CNN의 경로 길이 문제를 트랜스포머의 출발점으로 제시합니다.

01 · Attention in one slide

어텐션 한 장 요약

out = Σ softmax(score(q, kᵢ)) · vᵢ
  • 쿼리(Q)와 키(K)의 유사도로 가중치를 만들고, 그 비율로 값(V)을 섞는 소프트 룩업
  • 2014~16년에는 RNN에 붙은 보조 장치: 디코더가 인코더를 들여다보는 창구
  • 트랜스포머는 이것을 모델의 유일한 시퀀스 혼합 수단으로 올렸다
연도방식점수 함수
2014Bahdanau (가산)vᵀtanh(Ws + Uh)
2015Luong (곱셈)sᵀh, sᵀWh
2017Transformerqᵀk / √dₖ

Luong의 내적 방식은 행렬곱 한 번으로 계산돼 GPU에 유리했고, 트랜스포머 점수 함수의 직접적인 조상이다.

어텐션 연산 자체는 2015년에 이미 있었습니다. 트랜스포머의 새로움은 이 연산을 어디에, 어떻게 배치했느냐에 있습니다. 여기서부터 본론입니다.

02 · Architecture

트랜스포머 전체 구조

  • 인코더·디코더 각 N = 6층
  • 모든 서브층 출력 dmodel = 512
  • 서브층마다 LayerNorm(x + Sublayer(x))
  • 인코더 최종 출력이 모든 디코더 층의 K, V로 들어감
인코더 층은 셀프 어텐션과 FFN, 디코더 층은 여기에 인코더-디코더 어텐션이 더해진 세 서브층입니다. 차원을 512로 통일한 것은 잔차 연결에서 x와 Sublayer(x)를 더하기 위해서입니다.

02 · Data flow

인코더 한 층을 지나는 텐서 크기 (base, 문장 길이 n)

입력과 출력의 크기가 n × 512로 같기 때문에 같은 층을 6번 쌓을 수 있다. 크기가 n에 대해 제곱으로 커지는 곳은 어텐션 점수 행렬(n × n) 하나뿐이다.

이 슬라이드가 이후 계산 예제의 지도입니다. 계산 예제에서는 512를 4로, 8개 헤드를 1~2개로 줄여서 같은 흐름을 손으로 따라갑니다.

100002i/d에서 d=4이면 i=1일 때 분모가 100000.5 = 100. 차원이 높을수록 천천히 변한다.

위치 인코딩은 더하기입니다. 같은 단어라도 위치가 다르면 X가 달라집니다. pos 0인 I는 사인 값이 0, 코사인 값이 1이라 0, 1, 0, 1이 더해졌습니다.

Step 2 · Q, K, V

② 같은 X에서 Q, K, V를 만든다

q_I = x_I · WQ = [1, 1, 0, 1] · WQ 1열: 1·1 + 1·0 + 0·1 + 1·0 = 1 3열: 1·1 + 1·0 + 0·0 + 1·1 = 2 → q_I = [ 1, 1, 2, 2 ]

셀프 어텐션: Q·K·V 모두 같은 X에서 나온다. 다른 것은 곱하는 가중치 행렬뿐이다.

Q는 내가 찾는 것, K는 내가 가진 특징, V는 실제로 전달할 내용이라고 생각하면 됩니다. 셋은 같은 입력을 서로 다른 행렬로 투영한 결과입니다.

Step 3 · Scores

③ 점수 QKᵀ를 계산하고 √dk로 나눈다

s(I, love) = q_I · k_love = 1×2.54 + 1×1.84 + 2×2.55 + 2×1.85 = 13.18 s(I, I) = q_I · k_I = 1×2 + 1×2 + 2×1 + 2×1 = 8.00 √d_k = √4 = 2 → 13.18 / 2 = 6.59

행 = 쿼리(보는 쪽), 열 = 키(보이는 쪽). n × n 크기라서 문장 길이의 제곱으로 커진다.

점수 행렬의 i행 j열은 i번째 단어가 j번째 단어를 얼마나 참고할지의 원점수입니다. 예제는 W_Q와 W_K가 대칭 관계라 행렬이 대칭이지만, 일반적으로는 대칭이 아닙니다.

Step 4 · Softmax

④ softmax로 가중치를 만든다

I 행: [4.00, 6.59, 4.78] exp → [ e⁴ , e⁶·⁵⁹ , e⁴·⁷⁸ ] = [ 54.6, 727.8, 119.1 ] 합 = 901.5 ÷ 합 → [ 54.6/901.5, 727.8/901.5, 119.1/901.5 ] = [ 0.06, 0.81, 0.13 ]
  • 각 행의 합 = 1
  • “I”는 정보의 81%를 love에서 가져온다
  • 예제 가중치에서는 세 단어 모두 love에 집중
softmax는 각 행을 확률 분포로 바꿉니다. 점수 차이가 2.6 정도인데도 지수 함수 때문에 가중치는 0.06 대 0.81로 크게 벌어집니다. 그래서 스케일링이 중요합니다.

Step 5 · Weighted sum

⑤ 가중치로 V를 섞는다: Z = A · V

z_I = 0.06 × v_I + 0.81 × v_love + 0.13 × v_you = 0.06×[1, 2, 1, 2] + 0.81×[1.85, 2.54, 2.55, 1.84] + 0.13×[1.93, 1.58, 0.60, 2.91] 1열: 0.06 + 1.50 + 0.25 = 1.81 → z_I = [ 1.81, 2.38, 2.20, 1.99 ]
·
=
이제 각 단어의 벡터는 문장 전체의 정보를 가중 평균한 값이 됐습니다. 원래 I의 X는 1, 1, 0, 1이었지만 love의 정보가 많이 섞였습니다. 이 과정이 셀프 어텐션의 전부이고, 세 단어를 동시에 행렬곱으로 계산합니다.

Step 6 · Multi-head

⑥ 멀티헤드: 4차원을 2개 헤드 × 2차원으로

head 1 = Q,K,V의 1~2열 · head 2 = 3~4열, √d_k = √2 = 1.41 head 1, I 행: q=[1,1] 점수=[4.00, 4.38, 4.49] ÷1.41 → [2.83, 3.10, 3.17] → softmax [0.27, 0.35, 0.38] head 2, I 행: q=[2,2] 점수=[4.00, 8.80, 5.06] ÷1.41 → [2.83, 6.22, 3.58] → softmax [0.03, 0.90, 0.06]
Concat: z_I = [ 1.65, 2.03 | 2.36, 1.89 ] → · WO (4×4) → 4차원
  • head 1은 세 단어를 고르게 본다
  • head 2는 love에 90% 집중한다
  • 같은 입력, 다른 투영 → 다른 관계를 포착
  • 실제: 512 = 8 × 64, 비용은 단일 헤드와 비슷
헤드를 나누면 각 헤드가 다른 부분공간에서 어텐션을 계산합니다. 예제에서도 같은 단어 I가 헤드 1에서는 고르게, 헤드 2에서는 love에 집중합니다. 논문 실험에서 헤드 1개는 최적보다 BLEU가 0.9 낮았습니다. head 2 가중치 합이 0.99인 것은 반올림 때문입니다.

Step 7 · Add & Norm

⑦ 잔차 연결과 층 정규화

잔차: y_I = x_I + z_I = [1, 1, 0, 1] + [1.81, 2.38, 2.20, 1.99] = [2.81, 3.38, 2.20, 2.99] 평균: μ = (2.81 + 3.38 + 2.20 + 2.99) / 4 = 2.84 분산: σ² = (0.03² + 0.54² + 0.64² + 0.15²) / 4 = 0.18 → σ = 0.42 정규화: (y − μ) / σ = [ −0.03, 0.54, −0.64, 0.15 ] / 0.42 = [−0.07, 1.27, −1.51, 0.35]
  • 잔차: 어텐션이 망쳐도 원래 x가 그대로 남는다 → 깊게 쌓아도 학습됨
  • LayerNorm: 토큰마다 평균 0, 분산 1로 맞춘다 (학습 파라미터 γ=1, β=0 가정)
예제에서는 W_O를 단위행렬로 두고 단일 헤드 결과 Z를 사용했습니다. 잔차 연결이 있어야 6층 이상을 쌓아도 기울기가 흐릅니다. 층 정규화는 배치가 아니라 토큰 하나의 벡터 안에서 평균과 분산을 계산합니다.

Step 8 · FFN

⑧ FFN: 토큰마다 따로 4 → 8 → 4

x = [−0.07, 1.27, −1.51, 0.35] (⑦의 I 행) xW₁ = [ 1.79, 1.34, −2.78, −1.93, 1.62, 1.44, 1.69, −2.43] ReLU = [ 1.79, 1.34, 0 , 0 , 1.62, 1.44, 1.69, 0 ] · W₂ = [ 3.44, 2.15, 1.56, 0.72] + x (잔차) = [ 3.37, 3.42, 0.05, 1.07] → LayerNorm → 다음 층
  • 어텐션은 토큰을 섞고, FFN은 각 토큰을 변환한다
  • ReLU가 음수를 0으로 만들어 비선형성을 준다
  • 실제: 512 → 2048 → 512
  • 모든 위치에 같은 W₁, W₂를 쓴다 (b = 0 가정)
W2는 8×4 행렬로, 앞 4개 행은 단위행렬, 뒤 4개 행은 0.5씩 섞는 값으로 두었습니다. 어텐션은 가중 평균이라 그 자체로는 선형에 가깝고, 비선형 변환은 FFN이 맡습니다. 여기까지가 인코더 한 층입니다.

학습 때는 정답 문장 전체를 한 번에 넣고 마스크로 미래를 가린다 → 병렬 학습과 자기회귀 생성을 동시에 만족.

마스크가 없었다면 love는 you를 미리 볼 수 있었을 것입니다. 마스크를 쓰면 RNN처럼 한 단어씩 돌리지 않고도, 각 위치가 이전 단어만 본 결과를 한 번의 행렬곱으로 얻습니다. 예제에서는 같은 문장을 디코더 입력으로 가정했습니다.

Step 10 · Cross-attention & Output

⑩ 크로스 어텐션과 출력 확률

크로스 어텐션: Q는 디코더 벡터, K·V는 인코더 최종 출력. 계산은 ③~⑤와 같다.

디코더 마지막 출력이 y = [−0.07, 1.27, −1.51, 0.35] 라고 하면 로짓 = y · Eᵀ (출력층이 임베딩 행렬 E를 공유) I = [1,0,0,0]·y = −0.07 love = [0,1,1,0]·y = 1.27 − 1.51 = −0.24 you = [0,0,1,1]·y = −1.51 + 0.35 = −1.16 softmax → P = [ 0.46, 0.39, 0.15 ] → 다음 토큰 “I”
  • 입력 임베딩·출력 임베딩·softmax 직전 선형층이 가중치 하나를 공유
  • 실제: y(512) · Eᵀ(512 × 약 37,000) → 37,000개 단어의 확률
  • 추론 시 빔 크기 4로 탐색
로짓 계산은 출력 벡터와 각 단어 임베딩의 내적입니다. 즉 출력 벡터와 가장 비슷한 임베딩을 가진 단어의 확률이 높아집니다. 여기서 y는 설명을 위해 ⑦의 값을 그대로 가져왔습니다.

Part 4

실제 규모의 숫자

dmodel = 512, h = 8, dk = 64에서 무슨 일이 일어나나

04 · Why √dₖ

√dk로 나누지 않으면 생기는 일

q, k 성분이 평균 0, 분산 1 → q·k 의 분산 = d_k = 64 → 표준편차 = 8

스케일링 없음: 점수 [8, 0, −8]

softmax = [0.9997, 0.0003, 0.0000003]

거의 one-hot. 기울기 p(1−p) ≈ 0.0003 → 학습이 멈춘다

÷ √64 = ÷ 8: 점수 [1, 0, −1]

softmax = [0.665, 0.245, 0.090]

분포가 살아 있다. 기울기 p(1−p) ≈ 0.22 → 약 700배 큰 신호

계산 예제(dk=4)에서도 ÷2 전 점수 차이는 5.2, 나눈 뒤는 2.6이었다. dk가 64면 이 효과가 훨씬 커진다.

점수의 표준편차가 8이면 점수 차이 16 정도는 흔하게 생깁니다. 그러면 softmax가 한쪽으로 포화돼 기울기가 사라집니다. 루트 d_k로 나누면 분산이 1로 돌아옵니다. p(1-p)는 softmax 대각 미분 항을 단순화한 비교입니다.

각 위치는 512개의 서로 다른 주기를 가진 사인·코사인 값의 조합으로 표현됩니다. 시계의 초침, 분침, 시침이 함께 시각을 나타내는 것과 비슷합니다.

논문 당시 번역 문장은 n < d → 어텐션이 더 빠르다. 게다가 순차 연산이 O(1)이라 병렬화된다.

점수 행렬 메모리 (fp32, 8헤드, 층 1개·문장 1개)

n계산크기

긴 문맥에서는 n×n 행렬을 메모리에 쓰지 않는 FlashAttention 같은 기법이 필요해진다.

n이 d보다 작으면 셀프 어텐션이 RNN보다 연산이 적고, n이 커지면 역전됩니다. 메모리는 n의 제곱으로 늘어 3만 토큰이면 층 하나에 32기가바이트가 필요합니다. 이것이 이후 어텐션 최적화 연구의 출발점입니다.

Summary

정리: 트랜스포머를 이루는 것들

부품역할계산 예제에서 본 것
위치 인코딩RNN 대신 순서 정보 주입love: +[0.84, 0.54, 0.01, 1.00]
셀프 어텐션토큰 간 정보 교환, 병렬화I → love 가중치 0.81
멀티헤드여러 관계를 동시에head1 고르게 / head2 love 0.90
잔차 + LayerNorm깊게 쌓기 위한 안정성μ 2.84, σ 0.42로 정규화
FFN토큰별 비선형 변환4 → 8 → 4, ReLU로 3개 0
마스크병렬 학습 + 자기회귀 생성love 행: [0.06, 0.94, 0]

어텐션은 2015년에도 있었다. 트랜스포머의 기여는 이 부품들을 n × 512 → n × 512 블록으로 묶어 병렬화와 규모 확장이 가능한 구조를 만든 것이다.

이후 BERT는 인코더만, GPT는 디코더만 가져다 썼고, 블록 구조는 거의 그대로 유지됐습니다. 그만큼 이 블록 설계가 핵심이라는 뜻입니다.
