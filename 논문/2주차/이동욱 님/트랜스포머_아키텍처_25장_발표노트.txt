[Slide 02 / 25] 기존 seq2seq 모델의 구조와 한계
파트: Part 1. 배경과 전체 구조
부제: 고정 크기 컨텍스트 벡터(Context Vector) 병목과 장기 의존성 정보 손실

■ 핵심 요약
  1. 인코더가 입력 시퀀스 전체를 단 하나의 고정 크기 벡터(Context Vector)로 압축
  2. 입력 문장이 길어질수록 앞쪽 단어의 정보가 후반부에서 희석되거나 손실됨
  3. 어텐션 메커니즘으로 일부 보완했으나 여전히 RNN 기반 순차 구조의 제약을 받음

■ 발표자 해설 노트
기존 인코더-디코더 기반 seq2seq 모델은 입력 시퀀스 t=1부터 t=n까지의 정보를 하나의 은닉 상태 벡터에 압축합니다. 시퀀스가 길어지면 이 고정 길이 벡터가 병목(Bottleneck)으로 작용하여 초기 토큰 정보가 소실되는 문제가 발생합니다.

[Slide 03 / 25] RNN 순차 처리의 벽과 병렬화 전환
파트: Part 1. 배경과 전체 구조
부제: t-1 시점이 끝나야 t 시점을 계산하는 순차성 극복

■ 핵심 요약
  1. RNN 계열(LSTM/GRU)은 h_t = f(h_{t-1}, x_t) 구조로 GPU 병렬 연산에 불리함
  2. 트랜스포머는 문장 내 모든 단어 임베딩 행렬을 한 번에(Parallel) 입력받아 처리
  3. 단어 간 거리에 상관없이 O(1) 경로 길이로 직접 의존성을 연결하여 학습 속도 혁신

■ 발표자 해설 노트
RNN을 버린 가장 결정적인 이유는 병렬 연산입니다. RNN은 이전 시점의 은닉 상태가 계산되어야 다음 시점을 처리할 수 있어 대규모 코퍼스 학습에 한계가 있었습니다. 트랜스포머는 전체 문장을 행렬 곱셈 한 번으로 처리합니다.

[Slide 04 / 25] 트랜스포머 전체 아키텍처 조망
파트: Part 1. 배경과 전체 구조
부제: N개의 인코더 층과 N개의 디코더 층이 결합된 인코더-디코더 구조

■ 핵심 요약
  1. 좌측 인코더(Encoder) 블록과 우측 디코더(Decoder) 블록이 각각 N=6개 층으로 적층
  2. 입력과 출력 모두 임베딩 층 직후 포지셔널 인코딩(Positional Encoding)이 합산됨
  3. 최상위 인코더의 출력 벡터가 모든 디코더 층의 인코더-디코더 어텐션으로 전달됨

■ 발표자 해설 노트
트랜스포머 역시 큰 틀에서는 seq2seq처럼 인코더가 입력 문장을 인코딩하고, 디코더가 출력 문장을 생성합니다. 단, 인코더와 디코더 내부의 반복 단위(Unit)가 RNN 셀이 아니라 어텐션과 피드포워드 신경망으로 이루어진 층(Layer)이라는 점이 다릅니다.

[Slide 05 / 25] 트랜스포머의 주요 하이퍼파라미터
파트: Part 1. 배경과 전체 구조
부제: 원 논문(Base 모델) 기준 텐서 차원 흐름을 결정하는 4대 핵심 수치

■ 핵심 요약
  1. d_model = 512: 인코더와 디코더의 모든 입출력 및 임베딩 벡터의 고정 차원
  2. num_layers = 6: 하나의 블록 내부에 쌓이는 인코더 층과 디코더 층의 개수
  3. num_heads = 8: 멀티 헤드 어텐션에서 d_model을 나누어 병렬 수행하는 헤드 수 (512/8=64)
  4. d_ff = 2048: 포지션-와이즈 피드 포워드 신경망 내부 은닉층의 확장 차원

■ 발표자 해설 노트
트랜스포머 구조를 이해하기 위해 가장 먼저 짚고 넘어가는 4가지 하이퍼파라미터입니다. 모든 층을 지나면서도 텐서의 마지막 차원이 d_model(512)로 일정하게 유지된다는 점이 잔차 연결과 층 적층을 가능하게 합니다.

[Slide 06 / 25] 포지셔널 인코딩(Positional Encoding)의 필요성
파트: Part 2. 포지셔널 인코딩 · 어텐션
부제: 병렬 입력으로 사라진 단어의 순서 정보를 임베딩 벡터에 주입

■ 핵심 요약
  1. 단어를 순차적으로 받지 않고 행렬로 일괄 입력하므로 위치 순서 정보가 소실됨
  2. "나는 사과를 먹었다"와 "사과는 나를 먹었다"의 문맥을 구분하기 위해 위치 벡터 필수
  3. 단어 임베딩(Word Embedding) 벡터와 동일한 차원의 위치 벡터를 원소별 덧셈(+)으로 결합

■ 발표자 해설 노트
포지셔널 인코딩은 임베딩 벡터 뒤에 차원을 붙이는(Concat) 것이 아니라, 동일한 d_model 차원의 벡터를 더하는(Add) 방식입니다. 우측 시뮬레이터에서 위치(pos)와 차원 인덱스(i)를 조절해 사인·코사인 파형의 변화를 확인해 보세요.

[Slide 07 / 25] 포지셔널 인코딩 수식과 TensorFlow 구현
파트: Part 2. 포지셔널 인코딩 · 어텐션
부제: 사인(Sine)과 코사인(Cosine) 주기 함수를 이용한 위치 인코딩 계산

■ 핵심 요약
  1. 짝수 차원 인덱스(2i)에는 sin, 홀수 차원 인덱스(2i+1)에는 cos 함수 적용
  2. 주기 함수의 선형 변환 성질 덕분에 임의의 상대적 거리(pos + k) 표현 학습에 유리
  3. PositionalEncoding(tf.keras.layers.Layer) 구현 시 입력에 √d_model 스케일링 또는 위치 행렬 합산

■ 발표자 해설 노트
수식에서 분모의 10000^(2i/d_model)는 차원이 커질수록 주기가 기하급수적으로 길어지게 만들어, 모든 위치 pos마다 고유한 벡터 패턴을 생성합니다. 코드에서는 미리 최대 문장 길이만큼 pos_encoding 행렬을 계산해 두고 슬라이싱하여 더합니다.

[Slide 08 / 25] 어텐션의 3요소: Query, Key, Value와 3대 유형
파트: Part 2. 포지셔널 인코딩 · 어텐션
부제: 트랜스포머 내부에서 어텐션이 호출되는 3가지 지점 비교

■ 핵심 요약
  1. Query(질의), Key(색인), Value(값)의 유사도를 측정하여 가중합 벡터 산출
  2. 인코더 셀프 어텐션: Q = K = V (모두 인코더 입력 단어 벡터에서 파생)
  3. 디코더 마스크드 셀프 어텐션: Q = K = V (단, 미래 시점 토큰 마스킹 적용)
  4. 인코더-디코더 어텐션: Q는 디코더, K와 V는 최상위 인코더 출력에서 공급

■ 발표자 해설 노트
트랜스포머에는 어텐션 블록이 총 3군데 등장합니다. 첫 번째(인코더)와 두 번째(디코더 첫 서브층)는 Q, K, V의 출처가 같은 셀프 어텐션이고, 세 번째(디코더 두 번째 서브층)는 Q와 K/V의 출처가 다른 크로스 어텐션입니다.

[Slide 09 / 25] 스케일드 닷-프로덕트 어텐션(Scaled Dot-Product)
파트: Part 2. 포지셔널 인코딩 · 어텐션
부제: 내적 유사도 계산 후 √d_k로 스케일링하는 수학적 근거

■ 핵심 요약
  1. 어텐션 스코어 행렬 QK^T를 한 번의 행렬 곱셈으로 모든 토큰 쌍에 대해 동시 계산
  2. d_k가 커질수록 내적 값의 분산이 d_k배 커져 Softmax 기울기 소실(Saturation) 발생
  3. 분산을 1로 정규화하기 위해 √d_k로 나눈 뒤 Mask 적용 → Softmax → V 행렬 곱 수행

■ 발표자 해설 노트
단순 닷 프로덕트(QK^T) 대신 √d_k로 나누는 이유를 시뮬레이터에서 직접 확인할 수 있습니다. 스케일링을 끄면 특정 토큰 확률이 1.0에 치우쳐 다른 토큰의 그래디언트가 0에 가까워집니다.

[Slide 10 / 25] 멀티 헤드 어텐션(Multi-Head Attention)
파트: Part 2. 포지셔널 인코딩 · 어텐션
부제: d_model 차원을 h개 헤드로 분할하여 다각도 문맥을 병렬 학습

■ 핵심 요약
  1. 단일 어텐션 대신 d_model(512)을 num_heads(8)개로 분할해 d_k = 64 차원씩 병렬 수행
  2. 각 헤드마다 서로 다른 가중치 행렬(W_i^Q, W_i^K, W_i^V)을 학습하여 다양한 관계 포착
  3. 8개 헤드의 출력을 연결(Concatenate)한 후 출력 투영 행렬 W^O를 곱해 d_model 복원

■ 발표자 해설 노트
프리즘이 하나의 빛을 여러 파장으로 분산시키듯, 멀티 헤드 어텐션은 문장을 지시어 관계, 술어-목적어 관계, 시제 관계 등 여러 하위 표현 공간(Subspace)으로 나누어 동시에 바라봅니다. 전체 연산량은 단일 512차원 어텐션과 거의 동일합니다.

[Slide 11 / 25] 인코더(Encoder) 층의 내부 구조

■ 핵심 요약

  2. 서브층 2: 포지션-와이즈 피드 포워드 신경망(Position-wise FFNN)

[Slide 12 / 25] 인코더 셀프 어텐션의 문맥 이해 사례
파트: Part 3. 인코더(Encoder)
부제: "it"이 가리키는 대상을 문장 내부 관계만으로 추론하는 원리

  2. 셀프 어텐션 연산 시 대명사 "it"의 Query가 "animal"과 "tired"의 Key에 높은 가중치 부여

[Slide 13 / 25] 패딩 마스크(Padding Mask)의 원리와 구현
파트: Part 3. 인코더(Encoder)
부제: 문장 길이를 맞추기 위해 채운 <PAD> 토큰(0)을 어텐션에서 완벽히 배제

■ 핵심 요약
  1. 배치 내 문장 길이가 다를 때 짧은 문장 뒤에 숫자 0(<PAD>)을 채워 텐서 크기 통일
  2. <PAD> 위치가 Key에 포함되면 의미 없는 토큰에 어텐션 가중치가 할당되는 문제 발생
  3. 마스크 위치에 -1e9(매우 작은 음수)를 더하면 Softmax 통과 후 e^(-1e9) ≈ 0.0으로 소거됨

■ 발표자 해설 노트
create_padding_mask 함수는 입력 텐서 x에서 값이 0인 위치를 1.0으로, 나머지를 0.0으로 변환한 뒤 어텐션 스코어 행렬에 (mask * -1e9)를 더합니다. 아래 인터랙티브 시뮬레이터에서 토큰 길이를 줄여 <PAD>가 0.000으로 마스킹되는 과정을 확인하세요.

[Slide 14 / 25] 포지션-와이즈 피드 포워드 신경망(FFNN)
파트: Part 3. 인코더(Encoder)
부제: 각 단어 위치마다 독립적이고 동일하게 적용되는 비선형 변환

■ 핵심 요약
  1. 수식: FFNN(x) = max(0, xW_1 + b_1)W_2 + b_2 (두 번의 선형 변환 + ReLU 활성화)
  2. 은닉층 차원 d_ff = 2048로 4배 확장했다가 출력층에서 다시 d_model = 512로 축소
  3. 문장 내 모든 단어 위치(Position)에 대해 동일한 가중치 W_1, W_2를 공유하여 병렬 적용

■ 발표자 해설 노트
어텐션 서브층이 단어들 간의 문맥 정보를 섞어주는 역할을 한다면, Position-wise FFNN은 각 단어 위치별로 어텐션 결과를 비선형 공간으로 투영해 표현력을 높이는 역할을 합니다. 커널 크기가 1인 1D 합성곱 두 층과 수학적으로 동일합니다.

[Slide 15 / 25] 잔차 연결(Residual)과 층 정규화(Layer Norm)
파트: Part 3. 인코더(Encoder)
부제: 깊은 네트워크의 안정적 학습을 보장하는 Add & Norm 메커니즘

■ 핵심 요약
  1. 잔차 연결(Add): 출력 = x + Sublayer(x), 입력 정보를 보존하고 기울기 소실 방지
  2. 층 정규화(Norm): 배치 축이 아닌 각 샘플의 마지막 특성 차원(d_model)을 기준으로 정규화
  3. 학습 가능한 스케일(γ)과 시프트(β) 파라미터를 통해 표현력 유지: LN(x) = γ·(x-μ)/σ + β

■ 발표자 해설 노트
시퀀스 길이가 제각각인 NLP 데이터에서는 Batch Normalization보다 샘플 내부의 d_model 차원을 따라 평균과 분산을 계산하는 Layer Normalization이 훨씬 안정적입니다. 트랜스포머의 모든 서브층은 LayerNorm(x + Sublayer(x)) 구조를 따릅니다.

[Slide 16 / 25] 인코더에서 디코더로의 정보 전달
파트: Part 4. 디코더(Decoder) · 마스크
부제: 최상위 인코더 출력이 모든 디코더 층의 Key와 Value로 연결되는 구조

■ 핵심 요약

  2. 주의: 각 인코더 층이 1:1로 디코더 층에 연결되는 것이 아니라 마지막 인코더 출력만 전달
  3. 전달된 인코더 출력은 모든 디코더 층(1~6층)의 두 번째 서브층에서 K, V로 재사용됨

[Slide 17 / 25] 디코더의 3가지 서브층 구조
파트: Part 4. 디코더(Decoder) · 마스크
부제: 2개 서브층인 인코더와 달리 디코더는 3개의 서브층으로 구성

■ 핵심 요약
  1. 서브층 1: 마스크드 멀티 헤드 셀프 어텐션 (Look-Ahead Mask + Padding Mask 적용)
  2. 서브층 2: 멀티 헤드 인코더-디코더 어텐션 (Cross-Attention, Encoder Padding Mask 적용)
  3. 서브층 3: 포지션-와이즈 피드 포워드 신경망 (Position-wise FFNN + Add & Norm)

■ 발표자 해설 노트
디코더는 문장을 생성(번역)해야 하므로 자기 자신의 과거 출력을 참조하는 서브층 1과, 원본 입력 문장을 참조하는 서브층 2가 모두 필요합니다. 각 서브층 뒤에는 동일하게 Add & Norm이 붙습니다.

[Slide 18 / 25] 디코더 서브층 1: 룩-어헤드 마스크(Look-Ahead)
파트: Part 4. 디코더(Decoder) · 마스크
부제: 교사 강요(Teacher Forcing) 학습 시 미래 단어를 미리 보지 못하도록 차단

■ 핵심 요약
  1. 학습 시 디코더도 정답 문장 전체를 행렬로 한 번에 입력받아 병렬 학습(Teacher Forcing)
  2. t번째 단어를 예측할 때 t+1 이후 미래 토큰을 참조하는 "컨닝"을 막기 위해 상삼각 마스킹
  3. create_look_ahead_mask는 tf.linalg.band_part로 상삼각 행렬을 생성하고 패딩 마스크와 결합(maximum)

■ 발표자 해설 노트
룩-어헤드 마스크는 인과적(Causal) 구조를 유지하면서 병렬 학습을 가능하게 하는 핵심 장치입니다. 우측 인터랙티브 행렬에서 예측 시점 t를 변경하며 어떤 미래 토큰이 -1e9로 가려지는지 확인하세요.

[Slide 19 / 25] 디코더 서브층 2: 인코더-디코더 어텐션
파트: Part 4. 디코더(Decoder) · 마스크
부제: 디코더의 Query가 인코더의 Key·Value를 탐색하는 크로스 어텐션

■ 핵심 요약
  1. 셀프 어텐션이 아님: Query 행렬은 디코더 첫 번째 서브층의 출력에서 생성
  2. Key와 Value 행렬은 최상위 인코더 층의 출력에서 생성 (dec_padding_mask 적용)
  3. 번역 예: 디코더가 "student"를 생성할 때 인코더 입력의 "학생이다" 위치에 높은 어텐션 집중

■ 발표자 해설 노트
이 두 번째 서브층이 바로 seq2seq의 바다나우/루옹 어텐션과 동일한 역할을 수행하는 곳입니다. 현재 디코더가 생성하려는 단어(Query)가 원문의 어느 단어(Key)와 가장 관련 깊은지를 계산해 정보(Value)를 가져옵니다.

  2. Softmax 함수를 거쳐 전체 단어 집합 중 가장 확률이 높은 다음 토큰 예측

[Slide 21 / 25] TensorFlow 구현 1: MultiHeadAttention 클래스
파트: Part 5. 코드 구현 · 학습 · 요약
부제: 선형 투영 → 헤드 분할(split_heads) → 스케일드 어텐션 → 결합(concat)

[Slide 22 / 25] TensorFlow 구현 2: 인코더·디코더·전체 모델 조립
파트: Part 5. 코드 구현 · 학습 · 요약
부제: Functional API로 encoder_layer, decoder_layer 및 3종 마스크 연결

[Slide 23 / 25] 커스텀 학습률 스케줄러(CustomSchedule)
파트: Part 5. 코드 구현 · 학습 · 요약
부제: Warm-up 구간 선형 증가 후 역제곱근(rsqrt) 비율로 감쇠하는 학습 전략

■ 핵심 요약

트랜스포머는 층이 깊고 어텐션 가중치가 초기 분산에 민감하므로 Warm-up 스케줄링이 필수적입니다. 아래 인터랙티브 그래프에서 warmup_steps와 d_model을 조절해 학습률 곡선이 어떻게 변하는지 확인해 보세요.

[Slide 24 / 25] 손실 함수(Masked Loss)와 옵티마이저 설정
파트: Part 5. 코드 구현 · 학습 · 요약
부제: 패딩 토큰 오차를 제외한 정밀 손실 계산과 논문 기준 Adam 하이퍼파라미터

■ 핵심 요약
  1. loss_function: SparseCategoricalCrossentropy(from_logits=True, reduction="none") 사용
  2. mask = tf.math.logical_not(tf.math.equal(y_true, 0))로 <PAD> 위치의 손실을 0으로 마스킹
  3. 유효 토큰 개수로만 평균을 계산하여 문장 길이에 무관한 공정한 손실 산출
  4. 옵티마이저: Adam(learning_rate, beta_1=0.9, beta_2=0.98, epsilon=1e-9)

■ 발표자 해설 노트
실제 모델 컴파일 단계에서는 <PAD> 토큰을 맞혔는지 여부가 손실에 반영되지 않도록 반드시 마스킹된 손실 함수를 사용해야 합니다. 또한 논문에서 제안한 Adam의 beta_2=0.98, epsilon=1e-9 설정이 표준으로 쓰입니다.

[Slide 25 / 25] 총정리: 트랜스포머의 의의와 현대 LLM 계보
파트: Part 5. 코드 구현 · 학습 · 요약
부제: RNN의 시퀀스 병목을 끝내고 BERT·GPT·T5 시대를 연 현대 AI의 초석

■ 핵심 요약

  3. 디코더 중심 발전(GPT 시리즈, LLaMA, Claude, Gemini): 자기회귀 기반 초거대 생성형 AI(LLM)로 진화
