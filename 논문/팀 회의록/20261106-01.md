## 1. Object Detection 모델 계보 및 핵심 개념 정리

기존의 단순 이미지 분류(Classification)용 CNN을 넘어 위치 탐지(Detection) 및 분할(Segmentation)로 발전한 흐름을 정리함.

### 1) R-CNN (Region-based CNN)

* **핵심 기여**: CNN을 최초로 객체 탐지(Object Detection) 분야에 성공적으로 적용.

* **동작 방식**:

  * 입력 이미지에서 **Selective Search** 알고리즘을 사용해 약 2,000개의 Region Proposal을 추출.

  * 각 영역을 고정 크기($227 \times 227$)로 Warp/Crop하여 CNN을 통해 특징 벡터 추출.

  * 추출된 피처를 바탕으로 SVM(Support Vector Machine)을 사용해 클래스 분류 수행.

  * **Bounding Box Regression**을 통해 바운딩 박스 위치를 보정.

* **한계점**: 2,000개 영역 각각에 대해 CNN을 독립적으로 돌려야 하므로 처리 속도가 매우 느림.

### 2) Fast R-CNN

* **개선점**: **RoI (Region of Interest) Pooling** 도입.

* **동작 방식**:

  * 전체 이미지에 대해 단 **한 번만 CNN을 통과시켜 Feature Map을 생성**하고 이를 공유.

  * 원본 이미지에서 제안된 영역을 Feature Map 상의 RoI로 매핑한 뒤 RoI Pooling을 통해 고정 크기 벡터로 변환.

  * Softmax Classification과 Bounding Box Regressor를 통합하여 Multi-task Loss로 학습.

* **결과**: CNN 연산 중복을 제거하여 속도를 획기적으로 개선.

### 3) Faster R-CNN

* **개선점**: **RPN (Region Proposal Network)** 도입으로 완전한 End-to-End GPU 학습 달성.

* **동작 방식**:

  * 기존의 CPU 기반 Selective Search 병목을 해결하기 위해 Feature Map 위에서 영역 후보를 직접 제안하는 RPN 구축.

  * 다양한 크기와 비율의 Anchor Box(앵커 박스)를 사전에 정의하여 객체 후보를 효과적으로 추출.

* **결과**: 영역 제안부터 분류/회귀까지 전 과정을 GPU에서 고속 처리 가능.

### 4) Mask R-CNN

* **개선점**: **Instance Segmentation** 지원 및 **RoIAlign** 도입.

* **구조 및 동작**:

  * Faster R-CNN 백본 기반에 세 번째 분기인 **Mask Head(FCN)** 추가 (Bounding Box, Class, Mask를 동시에 예측).

  * **RoIAlign**: 기존 RoI Pooling의 반올림(Quantization)으로 인한 픽셀 위치 오차를 해결하기 위해, 양선형 보간법(Bilinear Interpolation)을 적용하여 서브픽셀 단위의 정확한 정렬 구현.

* **특징**: 바운딩 박스뿐만 아니라 픽셀 단위로 정확한 객체 윤곽(Edge)까지 검출.

### 5) 모델 비교 요약

| 모델 | 영역 제안 (Proposal) | 피처 추출 | 바운딩 박스 보정 | 인스턴스 마스크 | 속도 | 
| ----- | ----- | ----- | ----- | ----- | ----- | 
| **R-CNN** | Selective Search (CPU) | 각 RoI마다 CNN 수행 | Bounding Box Regression | 지원 안 함 | 매우 느림 | 
| **Fast R-CNN** | Selective Search (CPU) | 전체 이미지 1회 CNN + RoI Pooling | Bounding Box Regression | 지원 안 함 | 보통 | 
| **Faster R-CNN** | RPN (GPU, Anchor Box) | 전체 이미지 1회 CNN + RoI Pooling | RPN + Box Head | 지원 안 함 | 빠름 | 
| **Mask R-CNN** | RPN (GPU, Anchor Box) | 전체 이미지 1회 CNN + **RoIAlign** | RPN + Box Head | **Mask Head (FCN)** | 정밀함 (약간 느림) |

* **발표 시간**: 팀당 약 10분 내외.

* **슬라이드 구성**:

  * R-CNN $\rightarrow$ Fast R-CNN $\rightarrow$ Faster R-CNN은 핵심 발전 계기(ROI Pooling, RPN) 위주로 빠르게 요약 (장당 10\~30초).

  * 메인 주제인 **Mask R-CNN**(구조, RoIAlign, 멀티태스크 헤드)에 비중을 두고 설명.

* **발표자 선정**:
