🗺️ Mask R-CNN 7단계 파이프라인 & 텐서 형상 지도

Faster R-CNN의 기존 탐지 흐름(Backbone+FPN $\rightarrow$ RPN $\rightarrow$ Box RoIAlign) 위에 14×14 해상도의 Mask RoIAlign 및 FCN Mask Branch를 병렬 증설하여 인스턴스 픽셀 마스크를 완성하는 전체 흐름도입니다.

Step 1 · Backbone & RoI
MultiScaleRoIAlign
[N, 256, 14, 14]

Box의 7×7과 달리 픽셀 보존을 위해 2배 고해상도로 RoI 특징 추출

Step 2 · 4 Conv Tower
MaskHead Conv4
[N, 256, 14, 14]

4회 연속 3×3 Conv + ReLU로 마스크 윤곽선 특징 추출 및 정제

Step 3 · Upsampling
ConvTranspose2d
[N, 256, 28, 28]

학습 가능한 전치합성곱(Stride=2)으로 공간 해상도를 2배 확장

Step 4 · Predictor
MaskPredictor (1×1)
[N, K, 28, 28]

K개(COCO=80) 전경 클래스마다 독립적인 마스크 로짓 채널 생성

Step 5 · Target Gen
GT Target Mask
[P, 28, 28]

원본 GT 마스크에 roi_align(scale=1.0)을 적용해 정답 마스크 크롭

Step 6 · Loss Step
BCEWithLogitsLoss
Scalar Loss

Positive RoI의 GT 클래스 채널만 골라 픽셀별 독립 BCE 손실 계산

Step 7 · Inference & Paste
Canvas Post-Processing
[D, H, W] Boolean

예측 박스 크기로 Bilinear 보간 후 원본 이미지 Canvas에 복원

코드 ① MaskHead: 4단 Conv와 업샘플링

14×14 RoIAlign 특징을 4회 Conv로 정제하고, ConvTranspose2d로 28×28로 확장
Slide 11 / 21
Python · MaskHead (nn.Module) 
import torch.nn as nn
import torch.nn.functional as F

class MaskHead(nn.Module):
    def __init__(self, in_channels=256):
        super().__init__()
        layers = []
        for i in range(4):
            layers += [
                nn.Conv2d(
                    in_channels if i == 0 else 256,
                    256, kernel_size=3, padding=1
                ),
                nn.ReLU(inplace=True),
            ]
        self.conv_tower = nn.Sequential(*layers)
        self.deconv = nn.ConvTranspose2d(
            256, 256, kernel_size=2, stride=2
        )

    def forward(self, roi_features):
        x = self.conv_tower(roi_features)  # [N, 256, 14, 14]
        x = F.relu(self.deconv(x))         # [N, 256, 28, 28]
        return x

📥 입력 텐서 & 📤 출력 텐서

  • 입력 (roi_features): [N, 256, 14, 14] (RoIAlign의 출력 특징)
  • 중간 (conv_tower): [N, 256, 14, 14] (공간 크기 보존, 채널 256 유지)
  • 최종 출력 (x): [N, 256, 28, 28] (2배 업샘플링 완료된 특징 맵)

💡 왜 FC가 아닌 Fully Convolution인가?

Box Head는 좌표와 클래스 라벨이라는 1차원 벡터를 내므로 FC Layer(Flatten)를 씁니다. 그러나 마스크는 픽셀 간의 2차원 공간적 배치(Spatial Layout)가 생명입니다. FC 계층을 거치면 위치 정보가 완전히 파괴되므로, Mask Branch는 끝까지 합성곱 계층(Fully Convolutional)만을 고수합니다.

🔍 라인별 정밀 해설

kernel_size=3, padding=1
패딩을 1로 두어 $3 \times 3$ 합성곱 연산 후에도 특징 맵의 가로세로 크기가 14×14로 줄어들지 않고 완벽히 보존되도록 합니다.
ConvTranspose2d(..., stride=2)
전치합성곱 계층입니다. 일반 보간과 달리 역전파 학습을 통해 물체의 세밀한 윤곽선을 복원하는 가중치를 가집니다. kernel_size=2, stride=2로 정확히 2배 매칭하여 바둑판 왜곡(Checkerboard Artifacts)을 방지합니다.

코드 ② MaskPredictor: 클래스별 Mask Logit 생성

1×1 Conv를 적용해 K개 foreground 클래스마다 독립적인 Mask Logit 출력
Slide 12 / 21
Python · MaskPredictor (nn.Module) 
import torch.nn as nn

class MaskPredictor(nn.Module):
    def __init__(self, num_foreground_classes, in_channels=256):
        super().__init__()
        self.mask_logits = nn.Conv2d(
            in_channels, num_foreground_classes, kernel_size=1
        )

    def forward(self, mask_features):
        return self.mask_logits(mask_features)  # [N, K, 28, 28]

# 두 모듈 연결 (Slide 13의 MaskBranch 내부):
# mask_features = self.head(roi_features)     # [N, 256, 28, 28]
# mask_logits   = self.predictor(mask_features) # [N, K, 28, 28]

📥 텐서 형상 변환

  • 입력: [N, 256, 28, 28] (MaskHead 출력)
  • 연산: Conv2d(256, K, kernel_size=1)
  • 출력: [N, K, 28, 28] (K개 클래스 전용 마스크 로짓)

🎯 핵심 설계: 왜 K개 채널인가?

사람, 자전거, 자동차는 외형 윤곽선의 기하학적 특성이 완전히 다릅니다. 만약 1채널로 억지로 모든 클래스를 그리려 하면 모델에 큰 혼란이 옵니다. 클래스마다 독립적인 28×28 채널($K$개)을 할당함으로써 클래스 고유의 기하학적 실루엣 형태를 간섭 없이 분리 학습할 수 있습니다.

코드 ③ MaskBranch: RoIAlign과 모듈 통합 연결

MultiScaleRoIAlign으로 FPN에서 14×14 RoI를 추출하고 Head와 Predictor를 원스톱 연결
Slide 13 / 21
Python · MaskBranch (nn.Module) 
from torchvision.ops import MultiScaleRoIAlign
import torch.nn as nn

class MaskBranch(nn.Module):
    def __init__(self, num_foreground_classes):
        super().__init__()
        # Mask RoI path: output 14 x 14
        self.roi_align = MultiScaleRoIAlign(
            featmap_names=["0", "1", "2", "3"],
            output_size=14,
            sampling_ratio=2,
        )
        self.head = MaskHead(in_channels=256)
        self.predictor = MaskPredictor(num_foreground_classes)

    def forward(self, fpn_features, proposals, image_sizes):
        roi = self.roi_align(
            fpn_features, proposals, image_sizes
        )  # [sum(Ni), 256, 14, 14]
        features = self.head(roi)        # [sum(Ni), 256, 28, 28]
        logits = self.predictor(features) # [sum(Ni), K, 28, 28]
        return logits
💡 MultiScaleRoIAlign의 작동 메커니즘:
각 Proposal 박스의 물리적 면적 크기($w \times h$)에 따라 FPN 레벨($P_2 \sim P_5$)을 자동 선택합니다: $k = \lfloor 4 + \log_2(\sqrt{wh} / 224) \rfloor$. 작은 박스는 $P_2$에서, 큰 박스는 $P_5$에서 $14 \times 14$ 크기로 일괄 샘플링합니다.

코드 ④ Mask Target Generation: 28×28 GT 타깃 가공

전체 이미지 GT 마스크에 roi_align(spatial_scale=1.0)을 적용해 Positive RoI별 정답 타깃 고속 생성
Slide 14 / 21
Python · Mask Target Generation 
import torch
from torchvision.ops import roi_align

# Per image, prepare matched positive RoIs:
# positive_boxes: [P, 4] in image coordinates
# matched_gt_masks: [P, H, W] (GT mask matched to each RoI)
mask_targets = []
for boxes_i, gt_masks_i in zip(positive_boxes, matched_gt_masks):
    p = boxes_i.shape[0]
    roi_batch_ids = torch.arange(
        p, device=boxes_i.device
    )[:, None]
    rois = torch.cat([roi_batch_ids, boxes_i], dim=1)
    targets_i = roi_align(
        gt_masks_i[:, None].float(), rois,
        output_size=(28, 28),
        spatial_scale=1.0, aligned=True,
    )[:, 0]  # [P, 28, 28]
    mask_targets.append(targets_i)
target = torch.cat(mask_targets, dim=0)  # [P_total, 28, 28]

🔍 파이토치 고급 트릭 정밀 분석

spatial_scale=1.0
GT 마스크는 신경망 피처 맵이 아닌 원본 이미지 크기($H \times W$)이므로 축소 비율 없이 1.0을 지정합니다.
aligned=True
RoIAlign v2의 정렬 모드로, 0.5 픽셀 반올림 편향(Pixel Shift)을 완벽히 보정하여 서브픽셀 정밀도로 정답 마스크를 크롭합니다.

코드 ⑤ Class-Specific Mask Loss: GT 채널 선택과 BCE Loss

Positive RoI의 GT 클래스 채널만 골라내어 F.binary_cross_entropy_with_logits 계산
Slide 15 / 21
Python · Class-Specific Mask Loss 
import torch
import torch.nn.functional as F

# mask_logits: [P_total, K, 28, 28]
# labels: foreground class IDs in [1, K]
# target: [P_total, 28, 28], from previous step
labels = torch.cat(positive_labels, dim=0).long()
# Predictor channels are foreground-only: 0 ... K-1
class_idx = labels - 1
row_idx = torch.arange(
    labels.numel(), device=labels.device
)
selected_logits = mask_logits[row_idx, class_idx]
# selected_logits: [P_total, 28, 28]
loss_mask = F.binary_cross_entropy_with_logits(
    selected_logits, target
)

💡 Class-Mask Decoupling의 구현 핵심

mask_logits[row_idx, class_idx] 슬라이싱을 통해, 오직 Ground Truth 클래스에 해당하는 1개 채널만 선택하여 손실을 계산합니다. 나머지 $K-1$개 채널은 그래디언트를 받지 않으므로 클래스 간 픽셀 경합이 완전히 차단됩니다.

🛡️ 왜 binary_cross_entropy_with_logits인가?

Sigmoid와 BCELoss를 따로 호출하면 극단적인 값($x > 80$)에서 $\sigma(x)=1.0$으로 클리핑되어 $\log(0) \rightarrow -\infty$로 NaN 폭발이 발생합니다. with_logits는 내부 Log-Sum-Exp 항등식으로 NaN을 수학적으로 원천 차단합니다.

코드 ⑥ 추론: 예측 클래스의 Mask 채널 선택

Box Head가 예측한 Top-1 라벨 채널을 꺼내 sigmoid() 및 0.5 임계값 판정

Python · Inference Mask Selection 
import torch

# After box classification and NMS
# mask_logits: [D, K, 28, 28]
# labels: predicted foreground IDs in [1, K]
row_idx = torch.arange(
    labels.numel(), device=labels.device
)
class_idx = labels.long() - 1

# Gather the predicted class mask for each detection
selected_logits = mask_logits[row_idx, class_idx]
# [D, 28, 28]
mask_probs = selected_logits.sigmoid()
# independent per-instance mask probabilities
binary_masks = mask_probs > 0.5
# [D, 28, 28] boolean masks
추론 단계의 특징: Box Head와 NMS를 통과한 살아남은 $D$개의 확실한 객체에 대해서만 마스크를 추출합니다. 배경(0)을 제외하고 $1 \sim K$ 라벨을 - 1하여 0-based 인덱스로 정확히 매핑합니다.

코드 ⑦ 마스크 후처리: 28×28 Mask를 원본 이미지 좌표로 복원

박스 크기로 Bilinear Interpolation 확대 후, 원본 크기 Canvas에 페이스트하여 최종 마스크 완성
Slide 18 / 21
Python · Mask Post-Processing 
import torch.nn.functional as F

# mask_probs: [D, 28, 28], boxes: [D, 4]
# image_h, image_w: original image dimensions
full_masks = []
for prob, box in zip(mask_probs, boxes):
    x1, y1, x2, y2 = box.round().long().tolist()
    x1, y1 = max(0, x1), max(0, y1)
    x2, y2 = min(image_w, x2), min(image_h, y2)
    if x2 <= x1 or y2 <= y1:
        continue
    resized = F.interpolate(
        prob[None, None],
        size=(y2-y1, x2-x1),
        mode="bilinear", align_corners=False,
    )[0, 0]
    canvas = prob.new_zeros((image_h, image_w))
    canvas[y1:y2, x1:x2] = resized
    full_masks.append(canvas > 0.5)  # [H, W] Boolean Mask

🔍 4단계 기하학적 복원 파이프라인

1. 좌표 클리핑
round().long()으로 박스 좌표를 정수화하고 이미지 경계 $[0, W], [0, H]$ 내로 안전하게 클리핑합니다. 너비/높이가 0 이하인 빈 박스는 continue로 스킵합니다.
2. F.interpolate
$28 \times 28$ 확률 맵을 실제 박스 크기인 $(y_2 - y_1, x_2 - x_1)$ 크기로 Bilinear 보간을 거쳐 매끄럽게 고화질로 확대합니다.
3. Canvas Paste
원본 이미지 크기($H \times W$)의 빈 캔버스(`prob.new_zeros`)를 GPU에 만들고 슬라이싱 영역 canvas[y1:y2, x1:x2]에 확대된 확률을 삽입합니다.
4. canvas > 0.5
0.5 기준 이진 판정을 거쳐 원본 고화질 해상도와 1:1로 일치하는 최종 2D 불리언 인스턴스 마스크를 완성합니다.
