────────────────────────────────────────────────────────
【5페이지】 R-CNN (2014)
────────────────────────────────────────────────────────
"R-CNN은 Selective Search로 약 2,000개의 후보 영역을 만들고, 
각 영역마다 CNN을 따로 실행한 뒤 SVM으로 분류했습니다. 

CNN을 객체 탐지에 본격 도입했다는 의미가 크지만, 
후보마다 CNN을 반복 실행하기 때문에 연산량이 매우 컸습니다."


────────────────────────────────────────────────────────
【6페이지】 Fast R-CNN (2015)
────────────────────────────────────────────────────────
"Fast R-CNN은 이 문제를 해결합니다. 
전체 이미지에 CNN을 한 번만 실행하고, 
공유 Feature Map에서 RoI Pooling으로 특징을 추출합니다. 

분류와 박스 회귀를 하나의 네트워크에서 동시에 학습하는 
Multi-task Learning 구조로 바뀌었습니다."


────────────────────────────────────────────────────────
【7~9페이지】 Faster R-CNN (2015)
────────────────────────────────────────────────────────
"Faster R-CNN은 외부 Selective Search를 
Region Proposal Network, 즉 RPN으로 대체합니다. 

Anchor Box를 기반으로 객체 존재 점수와 좌표를 예측하고, 
NMS로 중복을 제거한 뒤 Detection Head로 넘깁니다. 

이제 Proposal 생성과 Detection이 하나의 학습 가능한 
Two-Stage 구조로 완전히 통합됩니다. 
이 구조가 Mask R-CNN의 직접적인 출발점입니다."


────────────────────────────────────────────────────────
【10페이지】 Mask R-CNN 전체 구조
────────────────────────────────────────────────────────
"Mask R-CNN은 Faster R-CNN 위에 
RoIAlign과 병렬 Mask Prediction Branch를 추가한 모델입니다. 

ResNet Backbone과 FPN을 거쳐 RPN이 Proposal을 만들고, 
RoIAlign 이후 Classification, Box, Mask Head가 병렬로 동작합니다. 
결과적으로 클래스, 박스, 픽셀 마스크를 동시에 예측합니다."


────────────────────────────────────────────────────────
【11페이지】 RoIAlign
────────────────────────────────────────────────────────
"가장 중요한 기술적 기여 중 하나가 RoIAlign입니다. 

기존 RoI Pooling은 좌표를 정수로 반올림하면서 
공간 정렬 오차가 발생했습니다. 
RoIAlign은 실수 좌표를 유지하고 
Bilinear Interpolation으로 샘플링해서 
Mask 경계 예측 정확도를 크게 높였습니다."


────────────────────────────────────────────────────────
【12페이지】 Mask Head와 Multi-task Loss
────────────────────────────────────────────────────────
"Mask Head는 14×14 특징을 입력받아 
4번의 3×3 Convolution 후 Deconvolution으로 28×28 마스크를 생성합니다. 

Loss는 Classification, Box Regression, Mask Prediction 
세 가지를 함께 최적화합니다. 
특히 Mask Loss는 각 RoI에서 Ground Truth 클래스에 해당하는 
채널만 선택해서 Binary Cross Entropy를 계산합니다."


────────────────────────────────────────────────────────
【13페이지】 Mask R-CNN Architecture Diagram
────────────────────────────────────────────────────────
"전체 구조를 다시 보시면, 
RoIAlign 이후 Box 경로와 Mask 경로가 분리되어 있으면서도 
같은 Proposal을 공유하는 형태입니다. 
이 설계가 인스턴스 분할의 핵심입니다."


────────────────────────────────────────────────────────
【14~16페이지】 Theory to Code 개요
────────────────────────────────────────────────────────
"실제 구현은 torchvision의 maskrcnn_resnet50_fpn_v2를 기준으로 합니다. 

모델을 로드하고, 이미지를 전처리한 뒤 추론하면 
boxes, labels, scores, masks 네 가지가 나옵니다. 
이 출력이 논문의 Classification, Box, Mask Branch와 
정확히 대응됩니다."


────────────────────────────────────────────────────────
【17~19페이지】 이론 ↔ 코드 매칭
────────────────────────────────────────────────────────
"모델 로드 시 Backbone, FPN, RPN, 세 개의 Head가 한 번에 구성됩니다. 

Forward를 실행하면 RoIAlign을 거쳐 
세 개 Head의 출력이 동시에 나옵니다. 

후처리에서는 confidence threshold로 필터링하고, 
마스크를 0.5 기준으로 이진화한 뒤 
원본 이미지 위에 시각화합니다."

────────────────────────────────────────────────────────
【24~30페이지】 코드 구현 상세 (빠르게)
────────────────────────────────────────────────────────
"핵심 코드만 간단히 보겠습니다.

MaskHead는 4단 Convolution으로 특징을 정제한 뒤 
Deconvolution으로 해상도를 28×28로 올립니다.

MaskPredictor는 1×1 Convolution으로 
클래스별 Mask Logit을 생성합니다.

MaskBranch는 MultiScaleRoIAlign으로 14×14 특징을 뽑고 
Head와 Predictor를 연결합니다.

학습 시에는 Positive RoI에 해당하는 GT Mask만 28×28로 만들고, 
해당 클래스 채널만 선택해 BCE Loss를 계산합니다.

추론 시에는 예측 클래스 채널을 골라 
Sigmoid 후 0.5로 이진화하고, 
원래 이미지 크기의 박스 위치에 붙여서 
최종 인스턴스 마스크를 완성합니다."


────────────────────────────────────────────────────────
【31페이지】 결론
────────────────────────────────────────────────────────
"정리하겠습니다. 

Mask R-CNN은 Two-Stage Detection과 
Pixel-level Instance Segmentation을 통합한 
중요한 연결점이자 기준점입니다. 

컴퓨터 비전의 진화는 단순한 모델 교체가 아니라, 
객체 후보 생성 → 특징 표현 → 공간 정렬 → 마스크 예측으로 
이어지는 문제 해결의 연속입니다. 

Mask R-CNN은 그 흐름을 이해하는 가장 좋은 출발점입니다.

이상입니다. 질문 받겠습니다."
