2. R-CNN: 객체 탐지의 출발점 (2014)

2014년 Ross Girshick 연구진이 발표한 모델입니다. 기존 컴퓨터 비전은 HOG, SIFT, Sliding Window 등 수작업 특징 추출이 주류였으나, R-CNN은 CNN을 활용하여 이미지에서 자동으로 특징을 학습하는 새로운 접근법을 제시했습니다.

아키텍처

Input Image ↓ Selective Search (약 2,000개 Region Proposal 생성) ↓ CNN Feature Extraction ↓ SVM Classification ↓ Bounding Box Regression

작동 원리

  1. Selective Search를 사용해 객체 후보 영역을 생성합니다.
  2. 각 후보 영역을 CNN에 입력합니다.
  3. CNN에서 특징 벡터를 추출합니다.
  4. SVM으로 객체 종류를 분류합니다.
  5. Bounding Box Regression으로 객체 위치를 보정합니다.

한계점

  • 약 2,000개 영역을 각각 CNN에 통과시켜 연산량이 매우 큽니다.
  • 학습 과정이 여러 단계로 분리됩니다.
  • 실시간 객체 탐지에 부적합합니다.
  • Instance Segmentation 기능이 없습니다.
핵심 의의: CNN을 객체 탐지에 본격적으로 적용한 중요한 출발점입니다.

3. Fast R-CNN (2015)

Fast R-CNN은 R-CNN의 가장 큰 비효율성을 해결했습니다. 기존 R-CNN은 각 Region Proposal마다 CNN을 실행했지만, Fast R-CNN은 전체 이미지에 CNN을 한 번만 적용합니다.

핵심 구조

Input Image ↓ CNN Backbone → Shared Feature Map ↓ RoI Pooling ↓ Classification (Softmax) + Bounding Box Regression

주요 발전

  • CNN Feature Map 공유
  • RoI Pooling 적용
  • Classification과 Bounding Box Regression을 하나의 네트워크에서 학습
  • Multi-task Loss 적용

대표적인 Loss 함수:

\[ L = L_{cls} + \lambda L_{loc} \]
  • \( L_{cls} \): 객체 분류 손실
  • \( L_{loc} \): Bounding Box 회귀 손실
  • \( \lambda \): 두 손실의 가중치
핵심 의의: CNN 연산을 공유하여 R-CNN보다 효율적인 학습 및 추론 구조를 구현했습니다.

4. Faster R-CNN (2015)

Faster R-CNN은 Region Proposal 생성 과정까지 신경망 내부로 통합했습니다. 기존 Selective Search를 대체하는 핵심 기술이 바로 RPN (Region Proposal Network)입니다.

RPN의 작동 원리

RPN은 CNN Backbone의 Feature Map을 입력으로 받아 객체가 존재할 가능성이 높은 영역을 예측합니다.

  • Anchor Boxes
  • Objectness Score
  • Bounding Box Regression
  • Non-Maximum Suppression (NMS)

전체 구조

1. Input Image 2. CNN Backbone 3. Feature Map 4. RPN → Region Proposals 5. RoI Pooling 6. Classification Head 7. Bounding Box Regression

Anchor Box란?

하나의 위치에서 서로 다른 크기와 종횡비를 갖는 사전 정의된 후보 Bounding Box입니다. 예: 128×128, 256×256, 512×512 및 다양한 종횡비 조합으로 여러 객체 형태에 대응합니다.

핵심 의의: Region Proposal 생성까지 딥러닝으로 학습할 수 있게 되면서 현대적인 Two-Stage Object Detector의 기반을 마련했습니다.

5. Mask R-CNN (2017): 가장 중요한 전환점

2017년 Kaiming He, Georgia Gkioxari, Piotr Dollár, Ross Girshick 연구진이 발표했습니다. 기존 Faster R-CNN에 Mask Prediction Branch를 추가한 것이 핵심입니다. Faster R-CNN은 객체의 위치와 종류만 탐지했지만, Mask R-CNN은 객체의 정확한 픽셀 영역까지 구분합니다.

5.1 Mask R-CNN의 핵심 아키텍처

Input Image ↓ ResNet-50 / ResNet-101 Backbone ↓ Feature Pyramid Network (FPN) ↓ Region Proposal Network (RPN) ↓ RoIAlign ↓ ┌─────────────┬─────────────┬─────────────┐ │ Class 분류 │ Box 위치 │ Mask 픽셀 분할 │ └─────────────┴─────────────┴─────────────┘

5.2 세 가지 핵심 출력 + Colab 코드 대응

출력 Branch 기능 결과 Colab 코드에서의 키
Classification Head 객체 종류 식별 사람, 자동차 등 pred["labels"]
Bounding Box Head 객체 위치 추정 좌표 및 크기 pred["boxes"]
Mask Head 픽셀 단위 객체 분할 Binary Mask pred["masks"]

예를 들어 하나의 이미지에 사람 3명과 자동차 2대가 있다면, 각각의 객체에 대해 독립적인 Mask를 생성합니다. 이것이 Semantic Segmentation과 Instance Segmentation의 차이입니다.

# Colab에서 추론 후 세 가지 출력을 받는 코드 with torch.no_grad(): pred = model([img_tensor])[0] boxes = pred["boxes"] # [N, 4] → Bounding Box Head labels = pred["labels"] # [N] → Classification Head scores = pred["scores"] # [N] → Objectness / Confidence masks = pred["masks"] # [N, 1, H, W] → Mask Head (Sigmoid 출력)
이론 ↔ 코드 연결: 논문의 세 개 Branch가 torchvision 구현에서는 하나의 딕셔너리로 깔끔하게 나옵니다. masks는 각 인스턴스마다 독립적인 Binary Mask이므로, 같은 클래스의 여러 객체도 서로 다른 마스크로 구분됩니다.

5.3 가장 중요한 기술: RoIAlign + 코드에서의 역할

Mask R-CNN의 가장 중요한 기여 중 하나입니다. 기존 RoI Pooling은 좌표를 정수 단위로 반올림하는 과정에서 공간적인 정렬 오차가 발생할 수 있으며, 이는 특히 픽셀 단위 Mask Prediction에서 큰 문제가 됩니다.

RoIAlign은 좌표를 불필요하게 정수화하지 않고, Bilinear Interpolation을 이용해 특징값을 계산합니다.

비교 항목 RoI Pooling RoIAlign
좌표 처리 정수 단위 반올림 실수 좌표 유지
특징 추출 Quantization Bilinear Interpolation
공간 정렬 오차 발생 가능 정밀한 정렬
Mask Prediction 상대적으로 불리 유리

RoIAlign의 핵심 수식:

\[ f(x,y) = \sum_{i,j} w_{ij} f(x_i, y_j) \]

여기서 \( w_{ij} \)는 주변 네 개의 픽셀에 적용되는 Bilinear Interpolation 가중치입니다.

Colab 코드에서의 RoIAlign:
torchvision의 maskrcnn_resnet50_fpn_v2는 내부적으로 RoIAlign을 사용합니다. 사용자가 직접 호출할 필요는 없지만, 모델 구조상 RPN이 제안한 Region에 대해 RoIAlign이 Feature Map에서 정확한 위치의 특징을 추출한 뒤 Mask Head로 전달합니다. 덕분에 마스크가 Bounding Box와 공간적으로 잘 정렬됩니다.

5.4 Mask Head + 실제 마스크 시각화 코드

Mask Head는 각 RoI에 대해 객체의 픽셀 단위 마스크를 생성합니다.

  • 4개의 3×3 Convolution Layer
  • 1개의 2×2 Deconvolution Layer
  • 1×1 Convolution
  • Per-class Binary Mask Prediction (Sigmoid + BCE)

대표적인 Mask 출력 크기는 28×28입니다. Mask Head가 Classification Head와 별도의 Branch로 작동하기 때문에 객체의 종류와 픽셀 영역을 동시에 학습할 수 있습니다.

# Colab에서 Mask Head 출력을 시각화하는 핵심 코드 for i, (box, score, label, mask) in enumerate(zip(boxes, scores, labels, masks)): m = mask[0] # [H, W], Sigmoid 출력 (0~1) # 0.5를 threshold로 Binary Mask 생성 colored_mask = np.zeros((*m.shape, 4)) colored_mask[m > 0.5] = (*color[:3], mask_alpha) ax.imshow(colored_mask) # 원본 이미지 위에 반투명 마스크 오버레이
이론 ↔ 코드 연결:
  • 논문의 “Per-class Binary Mask” → 코드의 mask[0] (각 인스턴스마다 독립)
  • Sigmoid 출력 → m > 0.5로 이진화
  • Classification과 Mask가 분리되어 있으므로, 같은 클래스의 여러 사람도 서로 다른 마스크를 가집니다.

5.5 Mask R-CNN Loss Function

\[ L = L_{cls} + L_{box} + L_{mask} \]
  • \( L_{cls} \): 객체 분류 Loss
  • \( L_{box} \): Bounding Box Regression Loss
  • \( L_{mask} \): Binary Mask Prediction Loss (BCE with Sigmoid)

원본 모델은 각 RoI에 대해 해당 Ground Truth 클래스의 Mask Loss를 계산하는 구조를 사용합니다.

추론 vs 학습: Colab 데모 코드는 추론(Inference) 전용입니다. Loss 계산은 학습 시에만 사용되며, torchvision의 학습 루프나 Detectron2에서 위 Multi-task Loss가 자동으로 적용됩니다.
핵심 의의: 객체 탐지와 Instance Segmentation을 하나의 통합 아키텍처에서 수행할 수 있게 만들었습니다.

6. Mask R-CNN 이후의 주요 발전

Mask R-CNN 발표 이후 연구자들은 크게 네 가지 문제를 해결하기 시작했습니다.

  • 작은 객체를 얼마나 정확하게 탐지할 것인가?
  • 겹쳐 있는 객체를 어떻게 구별할 것인가?
  • 객체 경계선을 얼마나 정밀하게 분할할 것인가?
  • CNN의 지역적 특징 추출 한계를 어떻게 극복할 것인가?

6.1 Feature Pyramid Network (FPN, 2017)

FPN은 Mask R-CNN의 성능을 향상시키는 핵심 기술입니다. 일반적인 CNN은 네트워크가 깊어질수록 Feature Map의 해상도가 낮아져 작은 객체의 세부 정보가 손실될 수 있습니다. FPN은 서로 다른 해상도의 특징을 결합합니다.

FPN의 세 가지 구성

  1. Bottom-up pathway: CNN을 통한 계층적 특징 추출
  2. Top-down pathway: 고수준 특징의 Upsampling
  3. Lateral connections: 동일 해상도 특징 결합

대표적으로 P2, P3, P4, P5 Feature Map을 생성합니다.

\[ P_i = \mathrm{Conv}_{1\times1}(C_i) + \mathrm{Upsample}(P_{i+1}) \]

이후 3×3 Convolution으로 Feature Map을 정제합니다.

기대 효과: 작은 객체 탐지 개선, 다양한 크기의 객체 처리, 고해상도 공간 정보 보존, Mask R-CNN의 Feature Extraction 성능 향상
FPN은 Mask R-CNN보다 먼저 독립적으로 제안된 기술입니다. 원본 Mask R-CNN 논문은 ResNet과 ResNet-FPN을 모두 실험했고, ResNet-FPN 기반 구조에서 우수한 성능을 보였습니다.

6.2 Cascade R-CNN (2018)

Cascade R-CNN은 Bounding Box의 품질을 단계적으로 개선하기 위한 모델입니다. 일반적인 Faster R-CNN은 하나의 Detection Head에서 객체의 위치를 추정하지만, IoU가 높은 객체만 학습시키면 데이터가 부족해지고, 낮은 IoU 기준으로만 학습하면 정확한 위치 추정에 한계가 생깁니다.

단계 IoU 기준 (예시) 역할
Stage 10.5초기 객체 탐지
Stage 20.6위치 정밀화
Stage 30.7고품질 Bounding Box
\[ B_1 \rightarrow B_2 \rightarrow B_3 \]

각 단계에서 이전 단계의 예측 결과를 다음 단계의 입력으로 전달합니다.

위 IoU 값은 구조를 설명하기 위한 대표적인 예시입니다. 실제 설정은 구현 및 실험 조건에 따라 달라집니다.

Mask R-CNN과 결합하면 Cascade Mask R-CNN이 됩니다. (Cascade Detection Head + Improved Bounding Box Regression + Mask Prediction Head)

6.3 PANet (2018)

PANet (Path Aggregation Network)은 FPN의 정보 전달 구조를 개선합니다. FPN이 Top-down 방향으로 고수준 특징을 전달하는 데 중점을 두었다면, PANet은 Bottom-up Path Augmentation을 추가합니다.

  • Bottom-up Path Augmentation
  • Adaptive Feature Pooling
  • Feature Fusion
  • Instance Segmentation 개선
항목 FPN PANet
Top-down 지원 지원
Bottom-up augmentation 기본 구조에는 없음 추가
Feature Fusion Lateral Connection 강화된 경로 및 Adaptive Pooling
주요 목표 다중 스케일 특징 전달 및 인스턴스 정보 강화

6.4 Hybrid Task Cascade (HTC, 2019)

HTC는 Detection과 Segmentation을 단계별로 연결하는 모델입니다. 일반적인 Cascade Mask R-CNN에서는 Detection과 Mask Prediction이 각 단계에서 연결되지만, HTC는 이 두 작업의 상호작용을 더욱 적극적으로 활용합니다.

  • Interleaved Execution
  • Mask Information Flow
  • Semantic Segmentation Branch
  • Multi-stage Feature Refinement
\[ \mathrm{Box}_1 \rightarrow \mathrm{Mask}_1 \rightarrow \mathrm{Box}_2 \rightarrow \mathrm{Mask}_2 \rightarrow \mathrm{Box}_3 \rightarrow \mathrm{Mask}_3 \]

이 구조를 통해 Mask Prediction 결과가 이후 Detection 단계에도 도움을 줄 수 있습니다.

7. Transformer 기반 Mask R-CNN의 발전

2017년 Mask R-CNN 발표 이후 컴퓨터 비전의 중요한 패러다임 변화가 일어났습니다. 바로 Transformer의 도입입니다. 기존 CNN은 주로 주변 픽셀을 기반으로 특징을 추출하는 반면, Transformer는 Self-Attention을 통해 이미지의 서로 멀리 떨어진 영역 간 관계도 학습할 수 있습니다.

7.1 Vision Transformer (ViT, 2020)

Vision Transformer (ViT)는 이미지를 일정 크기의 Patch로 분할한 뒤 Transformer Encoder에 입력하는 모델입니다.

1. Image Input 2. Patch Embedding 3. Positional Embedding 4. Transformer Encoder 5. Classification Head

Self-Attention 계산식:

\[ \mathrm{Attention}(Q,K,V) = \mathrm{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V \]
ViT 자체가 Mask R-CNN의 후속 모델은 아닙니다. Transformer를 컴퓨터 비전에 도입한 중요한 기반 기술입니다.

7.2 Swin Transformer (2021)

Swin Transformer는 CNN의 계층적 특징 추출 방식과 Transformer의 Attention을 결합한 구조입니다.

  • Hierarchical Feature Representation
  • Window-based Self-Attention
  • Shifted Window Mechanism
  • Multi-scale Feature Extraction

특히 Shifted Window 방식은 인접한 Window 간 정보 전달을 가능하게 합니다.

Swin Transformer는 Mask R-CNN의 Backbone으로도 활용할 수 있습니다.

Image → Swin Backbone → FPN → RPN → RoIAlign → Detection + Mask

7.3 Mask2Former (2021/2022)

Mask2Former는 Mask R-CNN의 단순한 개선 버전이 아니라, 다른 접근법을 사용하는 Transformer 기반 Segmentation 모델입니다. 논문의 핵심은 Masked Attention입니다.

  • Transformer Decoder
  • Masked Attention
  • Multi-scale Feature Processing
  • Mask Classification
  • Universal Segmentation (Semantic / Instance / Panoptic)

Mask R-CNN이 RoI 단위로 객체를 탐지하고 분할한다면, Mask2Former는 Query 기반으로 Mask를 예측합니다.

항목 Mask R-CNN Mask2Former
기본 구조 Two-Stage Detector Transformer
객체 후보 RPN Learnable Queries
RoIAlign 사용 사용하지 않음
특징 처리 CNN + FPN 중심 Pixel Decoder + Transformer
Mask 생성 RoI별 Mask Head Query별 Mask Prediction

Segment Anything Model (SAM)은 Meta AI가 발표한 범용 이미지 분할 Foundation Model입니다. Mask R-CNN과 가장 중요한 차이는 객체를 분할하는 방식입니다.

7.5 SAM 2 (2024)

SAM 2는 이미지 분할뿐 아니라 동영상에서 객체를 추적하면서 분할하는 기능으로 발전했습니다.

  • Memory Attention

따라서 SAM 2는 단일 이미지 중심의 Mask R-CNN과는 다른 방향으로 발전한 기술입니다.

9.1 CNN과 Transformer의 근본적인 차이

CNN 기반

  • Local Receptive Field
  • Convolution
  • Hierarchical Features
  • 공간적 지역 정보에 강점

Transformer 기반

  • Self-Attention
  • Global Context
  • Query Representation
  • 장거리 관계 학습
주의: CNN이 지역 정보만 처리하고 Transformer가 항상 전역 정보를 처리한다는 식으로 단순화해서는 안 됩니다. 현대 CNN도 넓은 수용영역을 확보할 수 있으며, Transformer도 Window Attention을 사용할 수 있습니다. 두 구조는 서로 경쟁하면서도 결합할 수 있습니다.

10. 이론 + Colab 코드 통합 정리

5절에서 설명한 Mask R-CNN의 핵심 이론을 Colab 실습 코드와 1:1로 대응시켜 정리합니다. 이론을 이해한 뒤 코드를 보면, 각 라인이 논문의 어떤 부분을 구현하는지 명확해집니다.

10.1 모델 로딩 = 전체 아키텍처 한 줄로 불러오기

논문의 ResNet-FPN Backbone + RPN + RoIAlign + 3개 Head 구조가 torchvision 한 함수로 제공됩니다.

from torchvision.models.detection import ( maskrcnn_resnet50_fpn_v2, MaskRCNN_ResNet50_FPN_V2_Weights ) weights = MaskRCNN_ResNet50_FPN_V2_Weights.DEFAULT # COCO pretrained (mask AP ≈ 41.8) model = maskrcnn_resnet50_fpn_v2(weights=weights) model.to(device) model.eval()
코드 이론적 의미 (5절 대응)
maskrcnn_resnet50_fpn_v2 ResNet-50 + FPN Backbone (6.1절) + RPN + RoIAlign + Mask Head
weights=DEFAULT COCO 2017로 학습된 전체 파라미터 (cls/box/mask 모두 포함)
model.eval() 추론 모드 (Dropout/BN 고정, Loss 계산 없음)

10.2 전처리 + 추론 = RPN → RoIAlign → Multi-task Head

transform = weights.transforms() # 논문 실험과 동일한 정규화 img_tensor = transform(image).to(device) with torch.no_grad(): pred = model([img_tensor])[0] # 한 번에 전체 pipeline 실행

내부적으로 일어나는 일 (이론 순서):

  1. Backbone + FPN이 Multi-scale Feature Map 생성
  2. RPN이 Region Proposal 생성 (Anchor + Objectness)
  3. RoIAlign이 각 Proposal의 정확한 특징 추출 (양자화 없음)
  4. Classification / Box / Mask Head가 동시에 예측

10.3 출력 딕셔너리 = 세 가지 Branch의 결과물

boxes = pred["boxes"] # Bounding Box Head 결과 [N, 4] labels = pred["labels"] # Classification Head 결과 [N] scores = pred["scores"] # Confidence masks = pred["masks"] # Mask Head 결과 [N, 1, H, W]
5.2절에서 설명한 세 Branch가 코드에서는 이 네 개의 키로 나옵니다. masks가 바로 “Instance Segmentation”의 핵심입니다.

10.4 Confidence Filtering + 마스크 이진화

# 1) 낮은 신뢰도 후보 제거 keep = pred["scores"] > confidence_threshold boxes = pred["boxes"][keep].cpu().numpy() masks = pred["masks"][keep].cpu().numpy() # 2) Sigmoid 출력을 Binary Mask로 변환 (논문의 Mask Head 후처리) for mask in masks: m = mask[0] binary = (m > 0.5) # threshold 0.5 # binary가 True인 픽셀만 색칠 → 시각화

이 부분이 논문의 “Per-class Binary Mask Prediction”을 실제로 화면에 보여주는 코드입니다. 같은 클래스의 여러 객체가 있어도 각각 다른 마스크를 가지기 때문에 Instance Segmentation이 성립합니다.

10.5 이론 ↔ 코드 전체 매핑표

Mask R-CNN 논문의 핵심 개념과 Colab 실습 코드가 어떻게 대응되는지 한눈에 볼 수 있도록 정리한 표입니다.

① 아키텍처 / 모델 구성

Mask R-CNN 이론 Colab / torchvision 코드 설명
ResNet-50 Backbone maskrcnn_resnet50_fpn_v2(...) 이미지에서 계층적 특징 추출
Feature Pyramid Network (FPN) 모델 이름에 _fpn_ 포함, 내부 자동 적용 Multi-scale Feature Map (P2~P5) 생성 → 작은 객체 탐지 개선

② 추론 파이프라인 (Inference Flow)

이론적 단계 Colab 코드 설명
입력 이미지 정규화 transform = weights.transforms()
img_tensor = transform(image)		 논문 실험과 동일한 Resize / Normalize 적용

masks = pred["masks"][keep] 등		 필터링된 인스턴스만 남김

binary = (m > 0.5)		 Sigmoid 출력(0~1)을 0.5 threshold로 Binary Mask 변환
Instance Segmentation 시각화 colored_mask[m > 0.5] = (*color, alpha)
ax.imshow(colored_mask)		 각 인스턴스마다 다른 색으로 마스크 오버레이

③ 출력 텐서 형태와 의미

출력 키 Shape 이론적 의미 후처리 예시
pred["boxes"] [N, 4] Bounding Box Regression 결과 x1, y1, x2, y2 = box
pred["labels"] [N] Classification Head 클래스 ID COCO_NAMES[label]
pred["scores"] [N] Confidence / Objectness Score scores > 0.5 필터링

④ 학습(Training) 관련 (참고)

Mask R-CNN 이론 Colab 데모에서의 상태 비고
Multi-task Loss
\( L = L_{cls} + L_{box} + L_{mask} \)		 사용하지 않음 (추론 전용) 학습 시에만 계산됨
RoIAlign의 미분 가능한 Bilinear Interpolation 모델 내부에 구현되어 있으나 역전파 없음 model.eval() + torch.no_grad()
Per-class Binary Mask Loss (BCE + Sigmoid) 추론 시에는 Sigmoid 출력만 사용 학습 시 Ground Truth 클래스 마스크에만 Loss 적용
한 줄 요약: model([img_tensor]) 한 번 호출로 RPN → RoIAlign → 세 Head가 모두 실행되고, 결과 딕셔너리의 boxes / labels / scores / masks가 바로 논문의 세 Branch 출력에 대응합니다.
실습 흐름 한 줄 요약:
모델 로드 → 공식 transform으로 전처리 → model([tensor]) 한 번 호출 → scores로 필터링 → masks를 0.5 threshold로 이진화 → 원본 이미지 위에 오버레이. 이 과정이 곧 “Mask R-CNN 추론 파이프라인”입니다.
주의: 현재 Colab 코드는 추론 전용입니다. Loss 함수나 RoIAlign의 미분 가능한 Bilinear Interpolation은 학습(Training) 단계에서만 직접 관여합니다. 학습 코드를 보고 싶다면 Detectron2 또는 torchvision의 학습 예제를 참고하세요.
