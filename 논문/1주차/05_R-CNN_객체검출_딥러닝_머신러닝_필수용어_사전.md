## 1. 평가 지표 (Metrics)

### 1-1. mAP (mean Average Precision, 전체 클래스 평균 정밀도)
- **개념**: 객체 검출 모델의 성능을 나타내는 **단 하나의 종합 성적표(기말고사 평균 점수)**입니다.
- **계산 방식**: 물체 클래스가 $K$개(사람, 자동차, 의자 등)라면, 각 클래스별 **AP(Average Precision, PR 곡선 아래 면적)**를 구한 뒤 산술평균합니다:
  $$\text{mAP} = \frac{1}{K} \sum_{k=1}^{K} \text{AP}_k$$
- **💡 1초 비유**: 국어(사람) AP 80점, 수학(자동차) AP 90점, 영어(신호등) AP 70점 $\rightarrow$ 평균 80점!
- **❓ 왜 단순 정확도(Accuracy) 대신 mAP를 쓸까?**:
  사진 1장의 90% 이상은 아무것도 없는 **'배경(Background)'**입니다. 모델이 물체를 1개도 못 찾고 *"아무것도 없음"*이라고만 대답해도 배경 맞춘 비율이 90%가 넘어버리는 **극단적 클래스 불균형(Class Imbalance)**이 발생하기 때문에, 찾은 물체와 위치의 질을 엄밀히 측정하는 mAP가 필수적입니다.

---

### 1-2. IoU (Intersection over Union, 교집합 대 합집합 비율)
- **개념**: 모델이 그린 예측 박스(Prediction)와 실제 정답 박스(Ground Truth)의 **공간적 일치율(0~1)**입니다:
  $$\text{IoU} = \frac{\text{교집합 면적 (Area of Overlap)}}{\text{합집합 면적 (Area of Union)}} = \frac{A \cap B}{A \cup B}$$
- **판정 기준**:
  - $\text{IoU} \ge 0.5$: PASCAL VOC 대회 기준 "합격선" (물체 위치를 잘 찾았다고 인정)
  - $\text{IoU} \ge 0.75$: COCO 엄격한 기준 (박스 테두리가 딱 들어맞아야 합격)
  - $\text{IoU} < 0.5$: 오답(False Positive) 판정

---

### 1-3. Precision(정밀도) vs Recall(재현율) & PR 곡선 작동 메커니즘
- **정밀도 (Precision) = $\frac{TP}{TP + FP}$**: 모델이 검출했다고 외친 것 중 **진짜 정답의 비율**
  - *비유*: 100% 확실한 용의자만 체포하는 **신중한 경찰** (무고한 사람 안 잡음)
- **재현율 (Recall) = $\frac{TP}{TP + FN}$**: 실제 존재하는 모든 정답 중 모델이 **찾아낸 비율**
  - *비유*: 조금이라도 의심되면 일단 다 체포하는 **의욕 넘치는 경찰** (범인을 안 놓침)
- **신뢰도(Confidence)와 PR 곡선의 실시간 작동 원리**:
  1. 모델이 예측한 박스들은 각각 **신뢰도(Confidence Score, 예: 0.95, 0.82, 0.40...)**를 가집니다.
  2. 신뢰도 임계값(Cutoff)을 **1.0에서 0.0으로 서서히 낮추면서** 검출된 박스들을 하나씩 추가로 채택해 나갑니다.
  3. 초반(임계값 0.9): 아주 확실한 박스 2개만 채택 $\rightarrow$ $TP=2, FP=0 \rightarrow$ **Precision = 100%, Recall = 40%**
  4. 중반(임계값 0.6): 애매한 박스 2개 추가 채택 (1개는 배경 오답) $\rightarrow$ $TP=4, FP=1 \rightarrow$ **Precision = 80%, Recall = 80%**
  5. 후반(임계값 0.2): 의심되는 박스 전부 채택 $\rightarrow$ $TP=5, FP=3 \rightarrow$ **Precision = 62.5%, Recall = 100%**
  6. 이 줄다리기를 그래프로 점을 찍어 이은 것이 **PR 곡선(우하향 곡선)**이며, 톱니 모양 요동을 보정하는 **계단식 보간(Interpolation)**을 거쳐 **곡선 아래 면적(AUC)을 적분한 것이 바로 AP(Average Precision)**입니다.

## 2. 머신러닝 & SVM & 오프셋 원리 (집중 해설)

### 2-1. 선형 서포트 벡터 머신 (Linear SVM) & "결정 경계면"이란?

#### ❓ "결정 경계면(Decision Boundary)을 찾는다는 게 무슨 뜻인가요?"
컴퓨터에게 데이터들이 주어졌을 때, **"이쪽은 강아지이고 저쪽은 고양이다"라고 두 집단을 갈라놓는 기준선/기준면**을 찾는 것을 뜻합니다.
- **1차원 (수직선)**: 시험 점수로 합격/불합격을 가를 때, `60점`이라는 **하나의 점(Point)**이 결정 경계입니다.
- **2차원 (평면)**: 키와 몸무게 좌표에 점들을 찍었을 때, 농구선수와 마라토너를 가르는 **하나의 직선(Line: $ax + by + c = 0$)**이 결정 경계입니다.
- **3차원 (공간)**: 키, 몸무게, 나이 3차원 데이터가 있다면, 공간을 양분하는 **평평한 벽/면(Plane)**이 결정 경계입니다.
- **고차원 (4차원 이상)**: R-CNN에서는 1개 박스마다 4,096차원 특징 벡터($x \in \mathbb{R}^{4096}$)가 나옵니다. 4096차원 공간을 반으로 똑 가르는 평평한 면을 수학에서 **'초평면(Hyperplane: $w \cdot x + b = 0$)'**이라고 부릅니다!

```
                [선형 SVM의 결정 경계면과 마진]
                
        Class A (강아지)            Class B (고양이)
           ●                        ■
              ●    서포트 벡터 A        ■   서포트 벡터 B
           ●      [●]              [■]       ■
       ────────────┆────────────────┆────────────
                   ┆    결정 경계면  ┆
                   ┆   (중앙 분리대) ┆
                   ┆        │       ┆
                   │◄──마진(Margin)─►│
```

#### 💡 왜 그냥 선을 안 긋고 "SVM(최대 마진)"을 쓸까? (DMZ 비유)
두 나라 사이에 국경선을 그을 때 한쪽 마을에 너무 바짝 붙여 선을 그으면 사소한 바람에도 오인 체포(오분류)가 일어납니다.  
SVM은 **"두 집단 사이의 완충도로 폭(마진, Margin)을 양쪽으로 가장 넓게 확보하는 가장 공평하고 안전한 한가운데 중앙선"**을 찾습니다!

#### 🛡️ 서포트 벡터(Support Vector)란?
국경선 바로 앞에 서 있는 **최전방 보초병 데이터들**입니다. 국경선에서 멀리 떨어진 후방 시민들은 경계선을 정하는 데 아무런 영향을 주지 않으며, **오직 이 보초병(Support Vector)들만이 경계면의 위치와 기울기를 단단히 지탱(Support)**합니다.

---

### 2-2. "오프셋(Offset)"이란 도대체 무슨 뜻인가?
**오프셋(Offset)**은 컴퓨터 공학이나 딥러닝에서 정말 자주 나오는 단어인데, 한국어로 가장 쉽게 번역하면:  
> **"어떤 기준점으로부터 얼만큼 떨어져 있는가 (상대적인 차이값, 편차, 보정값)"**

#### 💡 일상 속 오프셋 예시 3가지
1. **약속 장소**: 친구에게 *"위도 37.4979, 경도 127.0276으로 와라(절대 좌표)"*라고 하면 찾기 너무 어렵습니다. 대신 *"강남역 11번 출구(기준점)에서 **앞으로 50미터(오프셋)**만 와라!"*라고 하면 누구나 쉽게 찾습니다.
2. **시계 맞추기**: 내 시계가 현재 3분 늦다면, 표준 시계와의 차이인 **'+3분'이 바로 오프셋**입니다.
3. **컴퓨터 메모리**: 배열 시작 주소가 `1000번지`일 때, 4번째 데이터를 읽으려면 `1000 + 4`를 읽습니다. 여기서 `4`가 오프셋입니다.

#### 🎯 딥러닝 객체 검출에서 왜 오프셋을 쓸까?
1000픽셀짜리 화면 전체에서 물체 좌표를 맨땅에서 찍으면 숫자의 스케일이 너무 크고 불안정합니다.  
하지만 **미리 깔아둔 앵커 박스(기준점)**가 있다면, 신경망은 **"기준 닻에서 오른쪽으로 5픽셀, 위로 2픽셀만 옮겨라(오프셋)"**라는 작은 상대적 차이만 예측하면 되기 때문에 훨씬 안정적이고 똑똑하게 학습할 수 있습니다!

## 3. 백본 & 신경망 구조

### 3-1. 백본(Backbone) & Receptive Field
- **백본**: 입력 이미지로부터 고차원 시각 특징을 뽑아내는 신경망 본체 (AlexNet, VGG16, ResNet-50 등).
- **수용 영역 (Receptive Field)**: 특징 맵의 특정 픽셀 1개가 원본 이미지에서 바라보는 실제 시야각 영역. 층이 깊어질수록 수용 영역이 커져 전체적인 맥락(Context)을 이해함.

### 3-2. ResNet & 스킵 연결 (Skip Connection)
- 층이 100층 이상 깊어질 때 발생하는 **기울기 소실(Vanishing Gradient)** 문제를 입력값을 건너뛰어 더해주는 잔차 연결($F(x) + x$)로 해결한 초심층 신경망. Mask R-CNN의 강력한 백본.

### 3-3. FPN (Feature Pyramid Network, 특징 피라미드 네트워크)
- 깊은 층의 풍부한 의미(Top-down)와 얕은 층의 고해상도(Bottom-up)를 측면 연결(Lateral Connection)로 융합하여, **$P_2 \sim P_6$의 다중 스케일 특징 피라미드를 구축**. 작은 물체($AP_S$) 탐지 성능을 비약적으로 끌어올림.

## 4. 앵커 · RPN · 바운딩 박스 회귀 · NMS (집중 해설)

### 4-1. Anchor Box (앵커 박스): 앵커가 왜 앵커인가?

#### ⚓ "앵커 박스에서 앵커(Anchor, 닻)가 왜 앵커인가요?"
1. **바다의 닻**: 배가 망망대해에서 거친 물살에 휩쓸려 떠내려가지 않으려면 바닥에 **닻(Anchor)을 단단히 내려놓고 정박**해야 합니다.
2. **이전의 문제**: Faster R-CNN 이전에는 이미지의 수많은 픽셀 속에서 *"어디서부터 박스를 그려야 하지?"* 하고 아무 기준점 없이 망망대해를 헤맸습니다.
3. **해결책**: 개발진은 피처맵의 모든 격자점(Grid Point)마다 **닻(Anchor)을 쿵 내려놓듯 기준 참조 박스들을 고정으로 심어두었습니다**. 신경망은 맨땅에 박스를 그리는 게 아니라, **바닥에 내려진 닻(앵커)을 기준점으로 삼아 위치를 조정**합니다. 즉, **'위치를 붙들어 매어 두는 고정 기준점'** 역할을 하기 때문에 닻(Anchor)이라는 이름이 붙었습니다!

#### 📐 왜 9개의 앵커인가?
세상 모든 물체는 비율과 크기가 제각각입니다:
- 서 있는 사람: 키가 크고 홀쭉함 ($1:2$ 세로 비율)
- 달리는 승용차: 옆으로 길쭉함 ($2:1$ 가로 비율)
- 표지판, 얼굴: 정사각형 ($1:1$ 비율)
Faster R-CNN은 격자점마다 **3가지 크기($128^2, 256^2, 512^2$) $\times$ 3가지 종횡비($1:1, 1:2, 2:1$) = 총 9개의 닻**을 배치합니다.

### 4-2. Bounding Box Regression (바운딩 박스 회귀)

#### ❓ "왜 이름이 '회귀(Regression)'인가요?"
- **분류 (Classification)**: "강아지냐, 고양이냐"처럼 **정해진 이름표(이산 라벨)**를 맞춤.
- **회귀 (Regression)**: "내일 기온이 18.5도냐"처럼 **연속적인 숫자(실수값)**를 예측함.
- 박스를 맞추는 것은 "오른쪽으로 3.2픽셀, 위로 1.4픽셀, 폭은 1.15배"와 같이 **연속적인 수치(오프셋)를 예측해야 하므로 '회귀'**라고 부릅니다!

#### 🔢 구체적인 숫자로 보는 계산 공식 4단계
가상의 상황:
- 제안 박스(앵커) $P$: 중심 $x=100, y=100$, 가로 $w=50$, 세로 $h=50$
- 실제 정답 물체 $G$: 중심 $x=110, y=105$, 가로 $w=60$, 세로 $h=55$

**1단계: 모델이 학습해야 할 정답 오프셋($t$) 계산**
$$t_x = \frac{G_x - P_x}{P_w} = \frac{110 - 100}{50} = \mathbf{+0.2} \quad \text{("폭의 20%만큼 오른쪽으로 이동!")}$$
$$t_y = \frac{G_y - P_y}{P_h} = \frac{105 - 100}{50} = \mathbf{+0.1} \quad \text{("높이의 10%만큼 아래로 이동!")}$$
$$t_w = \log\left(\frac{G_w}{P_w}\right) = \log\left(\frac{60}{50}\right) = \log(1.2) \approx \mathbf{+0.182} \quad \text{("폭을 1.2배로 키워라!")}$$
$$t_h = \log\left(\frac{G_h}{P_h}\right) = \log\left(\frac{55}{50}\right) = \log(1.1) \approx \mathbf{+0.095} \quad \text{("높이를 1.1배로 키워라!")}$$

**2단계: 예측된 오프셋으로부터 최종 박스를 복원($\hat{G}$)하는 공식**
$$\hat{G}_x = P_x + P_w \cdot t_x = 100 + (50 \times 0.2) = \mathbf{110}$$
$$\hat{G}_w = P_w \cdot \exp(t_w) = 50 \times \exp(\log(1.2)) = 50 \times 1.2 = \mathbf{60}$$

> 💡 **왜 $\log$와 $\exp$를 쓸까?**  
> 박스 폭과 높이는 절대 음수가 될 수 없습니다(길이가 -10픽셀은 불가능). 지수 함수 $\exp(t_w)$는 $t_w$가 어떤 음수 값이 되더라도 **무조건 양수($>0$)를 보장하므로 박스가 뒤집히는 참사를 방지**합니다!

---

### 4-3. NMS (Non-Maximum Suppression, 비최대 억제)
- 동일한 물체에 중복으로 쳐진 수십 개의 박스 중 **가장 신뢰도가 높은 1등 박스만 남기고, 1등과 IoU가 높은(예: 0.7 이상) 나머지 박스들을 삭제**하는 필수 후처리 알고리즘.

## 5. 피처 정합: RoIPool vs RoIAlign

### 5-1. RoI Pooling: 왜 이름이 'Pooling'인가?

#### 🏊 "도대체 왜 이름에 'Pooling(풀링)'이 들어가나요?"
1. **'Pool'의 뜻**: 물웅덩이, 여러 자원을 하나로 모으다(Pooling). CNN에서 Pooling(Max Pooling)은 **여러 픽셀 중 가장 큰 대표값 하나만 쏙 뽑아내어 크기를 줄이는(다운샘플링) 연산**입니다.
2. **치명적인 문제 (FC 계층의 한계)**: 제안된 RoI들은 크기가 제각각입니다($120 \times 80$, $40 \times 190$ 등). 하지만 뒤에 연결된 **완전 연결(FC) 계층은 입력 뉴런 개수가 무조건 고정($7 \times 7 \times 512 = 25,088$개)**되어 있어서 크기가 다르면 행렬 곱셈 자체가 불가능하여 에러가 터집니다!
3. **해결책**: 어떤 크기의 RoI가 들어오든 똑같이 **가로 7칸 $\times$ 세로 7칸 = 총 49개의 작은 구역(Bin)**으로 바둑판처럼 나눕니다. 그리고 **각 칸(Bin) 안에 들어있는 픽셀들 중 가장 큰 값 1개씩을 맥스 풀링(Max Pooling)으로 쏙 뽑아냅니다**! 그러면 어떤 크기의 RoI도 마법처럼 **$7 \times 7$ 고정 크기**로 축약(Pool)됩니다.
4. 즉, **"관심 영역(RoI)을 칸별로 나누어 Max Pooling을 수행하는 층"**이기 때문에 **RoI Pooling**이라고 부르는 것입니다!

---

### 5-2. RoI Pooling vs RoIAlign 비교

| 비교 항목 | RoI Pooling (Fast / Faster R-CNN) | RoIAlign (Mask R-CNN) |
| :--- | :--- | :--- |
| **좌표 처리** | 정수로 반올림/내림 (**양자화, Quantization**) | 소수점 실수 좌표 그대로 유지 (**No Quantization**) |
| **샘플링 기법** | 정수 격자 내 Max Pooling | 빈(bin) 내부 4개 위치에서 **쌍선형 보간법 (Bilinear Interpolation)** |
| **위치 오차** | 피처맵 0.5px 오차 $\rightarrow$ **원본에서 8~16px 심각한 위치 어긋남** | **위치 오차 정확히 0 (완벽 정합)** |
| **효과** | 대략적인 박스 분류에는 충분했음 | **픽셀 단위 마스크 분할(Mask AP) 3~7포인트 수직 상승** |

## 6. 손실 함수 & 활성화 함수

### 6-1. Multi-task Loss (다중 작업 손실)
$$L = L_{\text{cls}} + \lambda [u \ge 1] L_{\text{box}} + L_{\text{mask}}$$
- $L_{\text{cls}}$: 정답 클래스 $u$에 대한 분류 손실 (Cross Entropy)
- $L_{\text{box}}$: 바운딩 박스 위치 오차 손실 (Smooth L1)
- $[u \ge 1]$: **아이버슨 스위치**. 배경($u=0$)일 때는 박스 위치를 맞출 필요가 없으므로 박스 손실을 $0$으로 끔!

### 6-2. Smooth L1 Loss (왜 L2 대신 쓸까?)
$$\text{Smooth}_{L1}(x) = \begin{cases} 0.5 x^2 & \text{if } |x| < 1 \quad (\text{0 부근에서는 부드러운 L2}) \\ |x| - 0.5 & \text{otherwise} \quad (\text{멀어지면 이상치에 강한 L1}) \end{cases}$$
- $L_2(x^2)$는 엉뚱한 이상치가 들어오면 기울기가 폭발하고, $L_1(|x|)$는 0에서 미분이 불연속적.
- Smooth L1은 0 근처에서는 매끄럽게 수렴하고 멀어지면 1차 선형으로 증가하여 **이상치에 매우 강건(Robust)**함.

## 7. 파이썬 & 파이토치(PyTorch) 구현 매핑

### 7-1. 행렬 브로드캐스팅을 활용한 벡터화된 IoU 계산 (Python/PyTorch)
```python
import torch

def box_iou(boxes1: torch.Tensor, boxes2: torch.Tensor) -> torch.Tensor:
    """
    boxes1: (N, 4) [x1, y1, x2, y2]
    boxes2: (M, 4) [x1, y1, x2, y2]
    반환: (N, M) 쌍별 IoU 행렬
    """
    area1 = (boxes1[:, 2] - boxes1[:, 0]) * (boxes1[:, 3] - boxes1[:, 1])
    area2 = (boxes2[:, 2] - boxes2[:, 0]) * (boxes2[:, 3] - boxes2[:, 1])

    # Broadcasting을 통한 교집합 좌상단/우하단 좌표 계산
    lt = torch.max(boxes1[:, None, :2], boxes2[:, :2])  # (N, M, 2)
    rb = torch.min(boxes1[:, None, 2:], boxes2[:, 2:])  # (N, M, 2)

    wh = (rb - lt).clamp(min=0)
    inter = wh[:, :, 0] * wh[:, :, 1]  # (N, M)

    union = area1[:, None] + area2 - inter
    return inter / union  # (N, M)
```

### 7-3. 객체 검출 DataLoader의 핵심: 왜 `collate_fn`이 필수일까?
```python
# 이미지마다 검출될 바운딩 박스 개수(고양이 2마리 vs 사람 10명)가 다르므로
# 기본 torch.stack 대신 튜플로 묶어주는 커스텀 collate_fn 필수
def collate_fn(batch):
    images = [item[0] for item in batch]
    targets = [item[1] for item in batch]
    return torch.stack(images, dim=0), tuple(targets)

data_loader = torch.utils.data.DataLoader(
    dataset, batch_size=4, shuffle=True, collate_fn=collate_fn
)
```

## 8. 1분 총정리 치트시트

1. **선형 SVM**: 두 데이터 집단 사이의 마진(도로 폭)을 최대화하는 가장 안전한 중앙 분리대(초평면)를 찾는 분류기.
2. **서포트 벡터**: 국경선 최전방에서 경계면을 지탱하고 있는 보초병 데이터들.
3. **오프셋(Offset)**: 기준점(강남역 11번 출구)에서 얼만큼 떨어져 있는지를 나타내는 상대적 차이값.
4. **Anchor(닻)**: 망망대해 같은 이미지에서 위치를 붙들어 매어 두기 위해 피처맵 격자마다 쿵 내려놓은 고정 기준 틀.
5. **Bounding Box Regression**: 연속적인 수치(오프셋)를 예측하여 박스를 정답 크기에 맞게 미세 성형수술 해주는 과정.
6. **RoI Pooling**: 크기가 제각각인 관심 영역을 $7 \times 7$개의 칸(Bin)으로 나눈 뒤 Max Pooling을 수행하여 FC 계층에 맞게 고정 크기로 축약하는 층.
7. **RoIAlign**: 정수 버림(양자화)을 없애고 쌍선형 보간(Bilinear Interpolation)으로 픽셀 오차를 0으로 만든 혁신 계층.
8. **mAP**: 전 클래스의 AP(PR 곡선 아래 면적)를 산술평균한 단 하나의 대표 점수.
